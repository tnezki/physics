Physics - Unit 7 - Section 7.5 - Demo Teacher Guide

Remove One Bulb

Series-versus-parallel removal demo - designed for 5-8 minutes

Time5-8 minutes
FormatTwo live circuits
Core ideaOne path vs branches

Why This Demo Fits Section 7.5

This is the exact conceptual entry point for Section 7.5: series has one path, parallel has branches, and a break affects only the paths it interrupts. It creates a visible basis for later current, voltage, equivalent-resistance, and safety reasoning.

Materials

  • Two low-voltage battery packs
  • Four identical miniature bulbs with holders
  • Wires and switches

Before Class

  1. Build one two-bulb series circuit and one two-bulb parallel circuit.
  2. Verify all bulbs work and label the circuits A and B without naming the connection type yet.

Suggested Flow

MinutesProjected PhaseTeacher Focus
1Show both circuitsEstablish that both operate.
2Predict removal effectsRequire separate predictions for A and B.
1Remove series bulbAsk which path is broken.
1Remove one parallel-branch bulbAsk which path remains complete.
1-2BridgeMove from visible path evidence to circuit rules.

Expected Observations / Evidence

Removing one bulb from the single-path circuit opens the only route, so both go out. Removing one bulb from one branch of the parallel circuit leaves the other branch complete, so its bulb stays lit.

Watch for: Do not overgeneralize brightness from bulb appearance alone; bulb resistance changes with temperature. The demo is about paths, not a quantitative equivalent-resistance lab.

Transition Into Notes

The notes formalize series/parallel/mixed paths, voltage/current patterns, equivalent resistance, overloads, fuses, circuit breakers, and short circuits.
