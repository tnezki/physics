2.1 Motion and Reference Frames

Learning Target: Students will explain that motion is relative and describe an object’s motion using an appropriate frame of reference.

Notes Example

U2-S1-NOTE-EX01 — Notes Example

A cup sits on a tray inside a train moving north. Describe the cup’s motion relative to (a) the tray and (b) a person standing on the platform.

Teacher information

Answer: Relative to the tray the cup is at rest. Relative to the platform observer the cup moves north with the train.

U2-S1-NOTE-EX02 — Notes Example

A passenger says, “The station is moving backward.” State the reference frame that makes this description reasonable and explain why a person on the platform would describe the same situation differently.

Teacher information

Answer: The passenger is using the train as the reference frame. A platform observer normally uses Earth or the platform as the frame and says the train moves forward while the station stays fixed.

U2-S1-NOTE-EX03 — Notes Example

Positions using the flagpole as the reference
ObjectPosition relative to flagpole
Bench4 m east
Bike rack9 m east
Tree3 m west

A student walks from the bench to the tree. Describe the change in position without switching reference objects.

Teacher information

Answer: The student moves 7 m west relative to the flagpole, from +4 m to -3 m if east is positive.

U2-S1-NOTE-EX04 — Notes Example

A headline says, “The satellite is motionless.” Explain why the statement is incomplete even if the satellite remains above nearly the same place on Earth.

Teacher information

Answer: Motionless must be relative to a stated frame. It can stay nearly fixed relative to a point on Earth while still moving relative to other frames such as the Sun.

U2-S1-PS3-Q01 — Practice Set 3

  1. At rest relative to the cargo floor; moving west relative to the traffic light.
  2. moving with respect to every possible observer
  3. at rest relative to the road only
  4. moving opposite the vehicle relative to its seat

U2-S1-PS3-Q02 — Practice Set 3

A rider on a tour boat moving north says the pier moves south. Name the rider’s reference frame and give the Earth-frame description.

  1. The rider must be using the Earth frame.
  2. The rider uses the tour boat as the frame. In the Earth frame the pier is fixed and the tour boat moves north.
  3. The outside object changes direction because the vehicle accelerates.
  4. Reference frames apply only to objects at rest.

U2-S1-PS3-Q03 — Practice Set 3

Using a signpost as the reference, point A is 4 m east and point B is 6 m west. An object moves from A to B. State its initial and final positions if east is positive, then give its displacement.

  1. Initial and final signs are both positive.
  2. Displacement is total path length without direction.
  3. Initial +4 m; final -6 m; displacement -10 m (10 m west).
  4. Changing the reference point during the calculation is required.

U2-S1-PS3-Q04 — Practice Set 3

A motion report says, “The lunchbox is moving.” Rewrite it so the statement is unambiguous by naming a reference frame and direction.

  1. A motion statement never needs a reference object.
  2. Direction alone identifies a complete reference frame.
  3. Only the object’s mass is missing from the statement.
  4. Example: The lunchbox is moving east relative to the roadside mailbox.

U2-S1-PS3-Q05 — Practice Set 3

Two observers disagree: one says the helmet is at rest and one says it moves north. Give a situation involving a moving train in which both descriptions are correct.

  1. The helmet can be fixed inside the moving train: at rest in the vehicle frame and moving north in the Earth frame.
  2. Only one observer can have a valid motion description.
  3. An object fixed in a vehicle must also be fixed to Earth.
  4. Different frames change the event rather than its description.

U2-S1-PS3-Q06 — Practice Set 3

A passenger walks west through a moving ferry. Which reference object should be named before deciding whether the passenger’s speed is zero, small, or large? Explain.

  1. The passenger’s frame is irrelevant once a direction is named.
  2. The reference object/frame must be named because the measured motion depends on what the passenger is compared with.
  3. All frames must measure the same velocity.
  4. A useful frame is determined only by the object’s mass.

U2-S1-PS3-Q07 — Practice Set 3

An airport shuttle is stopped beside the terminal wall. The water bottle sits inside. Compare the water bottle relative to the vehicle and the outside object now, then after the vehicle begins moving south.

  1. The object changes motion relative to the vehicle when the vehicle starts.
  2. The Earth-frame description stays at rest after departure.
  3. While stopped it is at rest relative to both. Afterward it remains at rest relative to the vehicle but moves south relative to the outside object.
  4. Both frames must switch reference objects at the same time.

U2-S1-PS3-Q08 — Practice Set 3

A diagram shows a moving walkway moving east past a fixed floor tile. Where could an observer stand to describe the vehicle as at rest? Where could an observer stand to describe it as moving?

  1. The moving observer must always report the vehicle moving.
  2. The roadside observer must report the vehicle at rest.
  3. Observer location cannot affect a relative-motion description.
  4. An observer moving with the moving walkway can describe it as at rest; an observer fixed near the floor tile describes it as moving east.

U2-S1-PS3-Q09 — Practice Set 3

Which statement best explains why a moving delivery van can serve as a reference frame?

  1. A reference frame is valid only when it is attached to Earth.
  2. A moving frame is valid only when its speed is zero.
  3. Changing reference frames changes the physical laws rather than the description.
  4. Any clearly stated frame can be used to describe relative motion, including a moving vehicle.

U2-S1-PS3-Q10 — Practice Set 3

A tour boat moves north. A rider tosses the camera straight up and catches it. Explain why the rider and the pier observer can describe the horizontal motion differently without disagreeing about the event.

  1. The rider and Earth observer must see identical horizontal paths.
  2. They use different reference frames: the rider can describe the object as staying near the rider horizontally, while the Earth observer sees horizontal motion with the vehicle.
  3. The object loses all horizontal motion when released.
  4. Reference frames matter only before the object is dropped.

U2-S3-NOTE-EX01 — Notes Example

A skateboarder’s velocity changes from 2 m/s east to 10 m/s east in 4 s. Calculate the acceleration and state its direction.

Teacher information

Answer: $2\text{ m/s}^2$ east.

Solution: $a=(10-2)/4=2\text{ m/s}^2$.

U2-S3-NOTE-EX02 — Notes Example

Take east as positive. A bicycle changes velocity from +12 m/s to +4 m/s in 4 s. Find the acceleration. Is the bicycle speeding up or slowing down?

Teacher information

Answer: $-2\text{ m/s}^2$; it is slowing down because velocity and acceleration have opposite signs.

Solution: $a=(4-12)/4=-2\text{ m/s}^2$.

U2-S3-NOTE-EX03 — Notes Example

Use the dot spacing to explain why the middle row represents speeding up and the bottom row represents slowing down.

Teacher information

Answer: Increasing spacing means more distance is covered in each equal time interval; decreasing spacing means less distance is covered in each interval.

U2-S3-NOTE-EX04 — Notes Example

A car moves around a circular track at a steady 12 m/s. Explain why it is accelerating even though its speed does not change.

Teacher information

Answer: Its direction changes continuously, so its velocity changes; a change in velocity is acceleration.

U2-S3-NOTE-EX05 — Notes Example

Use two points on the graph to calculate the acceleration. Explain how the graph’s slope connects to the calculation.

Teacher information

Answer: $2\text{ m/s}^2$; the slope $\Delta v/\Delta t$ is acceleration.

Solution: $a=(8-0)/(4-0)=2\text{ m/s}^2$.

Teacher information

Answer: 30 m/s at 3 s and 60 m/s at 6 s downward.

Solution: $v=(10)(3)=30\text{ m/s}$ and $v=(10)(6)=60\text{ m/s}$.

U2-S4-NOTE-EX03 — Notes Example

The straight-line model assumes equal distance is added every second. Explain why that assumption conflicts with an object whose speed is increasing during ideal free fall.

Teacher information

Answer: If speed increases each second, the object must cover more distance in later equal-time intervals; distance cannot increase by the same amount each second.

Solution: Increasing speed means increasing distance per equal time interval.
