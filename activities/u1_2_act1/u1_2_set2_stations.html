Station 1 Answers

Question 1

For $g(x)=x^2-1$, find $g(-2)$.

Solution: $g(-2)=(-2)^2-1=4-1=3$.

Question 2

A rule is described as "triple the input, then subtract $8$." Generate four ordered pairs using inputs $0,1,2,3$.

Solution: The rule is $y=3x-8$. Inputs $0,1,2,3$ give ordered pairs $(0,-8),(1,-5),(2,-2),(3,1)$.

Question 3

Analyze the structure of these two rules: $f(x)=2(x+3)$ and $g(x)=2x+6$. Do they always give the same output for the same input, or only sometimes? Justify with structure and one substitution check.

Solution: $f(x)=2(x+3)$ distributes to $2x+6$, which is exactly $g(x)$. They always give the same output. Check: at $x=1$, $f(1)=2(4)=8$ and $g(1)=2+6=8$.

Question 4

A table for an input-output rule is flawed: $(0,3),(1,6),(2,9),(2,12),(3,12)$. Revise the relation in two different ways: one revision that makes it a function with a constant increase, and one revision that makes it a function but not a constant-increase rule. Explain both choices.

Solution: Constant-increase revision: replace $(2,12)$ with $(3,12)$ and replace the old $(3,12)$ with $(3,12)$? A cleaner set is $(0,3),(1,6),(2,9),(3,12)$, which follows $y=3x+3$. Function but not constant-increase revision: keep one output for each input, such as $(0,3),(1,6),(2,9),(3,15)$; each input has one output but the changes are $3,3,6$.

Question 5

Use order of operations to simplify.

  1. $5-2\cdot3^2$
  2. $(-2)^2$
  3. $18\div3+4(2)$
  4. $7+|-9+4|$
Solution:
  1. $5-2\cdot3^2=5-18=-13$.
  2. $(-2)^2=4$.
  3. $18\div3+4(2)=6+8=14$.
  4. $7+|-9+4|=7+5=12$.

Question 6

Evaluate each root expression.

  1. $\sqrt[3]{27}$
  2. $\sqrt{144}$
  3. $\sqrt{3^2}$
  4. $\sqrt[4]{2^4}$
Solution:
  1. $\sqrt[3]{27}=3$.
  2. $\sqrt{144}=12$.
  3. $\sqrt{3^2}=\sqrt9=3$.
  4. $\sqrt[4]{2^4}=2$.

Question 7

Substitute $x=-2$ and $y=-5$ into each expression.

  1. $1-2x+3y$
  2. $x^2-y$
  3. $\frac{y-x}{3}$
Solution:
  1. $1-2(-2)+3(-5)=1+4-15=-10$.
  2. $(-2)^2-(-5)=4+5=9$.
  3. $\frac{-5-(-2)}{3}=\frac{-3}{3}=-1$.

Question 8

Evaluate $|2x-7|+x^2$ for $x=-3$ and for $x=4$. Which input gives the larger output, and by how much?

Solution: For $x=-3$: $|2(-3)-7|+(-3)^2=|-13|+9=22$. For $x=4$: $|8-7|+16=17$. The input $-3$ gives the larger output by $5$.

Question 9

A rectangular pattern has expression $2(l+w)$ for its border length. Evaluate the expression for $l=7.5$ and $w=3.25$, then state what the value represents.

Solution: $2(l+w)=2(7.5+3.25)=2(10.75)=21.5$. The border length is $21.5$ units.

Question 10

Rewrite $5(2x-3)+4x$ as a simplified expression. Show both the distribution step and the combining-like-terms step.

Solution: $5(2x-3)+4x=10x-15+4x=14x-15$.

Question 11

The area model is intended to represent $(x+2)(x+3)$, but one cell is incorrect. Identify the mismatch, revise the model, and explain how the product should expand.

Solution: For $(x+2)(x+3)$, the cells should be $x^2,3x,2x,6$. The mismatch is the bottom-right cell; it should be $6$, not $5$. The expanded product is $x^2+5x+6$.

Question 12

Write a context where $4(a+3)$ and $4a+3$ would mean different things. Evaluate both for the same value of $a$ and explain the difference in meaning.

Solution: Example: $4(a+3)$ could mean $4$ groups each with $a+3$ objects, while $4a+3$ could mean $4$ objects in each of $a$ groups plus $3$ extra. For $a=5$, $4(a+3)=32$ but $4a+3=23$, so the meanings and totals differ.

Question 13

A graph crosses the vertical axis at $({0},{12})$. In a situation about a water tank, what could ${12}$ represent?

Solution: The $12$ could represent the starting amount of water in the tank when the input time is $0$.

Question 14

The scatter plot shows practice days and score gain. Describe the overall association and identify one point that supports your description.

Solution: The scatter plot shows a positive association: as practice days increase, score gain tends to increase. One supporting point is any upper-right point showing more practice days with a higher score gain.

Question 15

A rule has the same output for every input. Construct an example table and symbolic rule, then explain why the output is constant even as the input changes.

Solution: Example table: $(0,5),(1,5),(2,5),(3,5)$. Symbolic rule: $y=5$. The output is constant because the rule ignores the input and always returns $5$.

Question 16

A school club’s table shows inputs ${0}$, ${1}$, ${2}$, ${3}$ with outputs ${10}$, ${14}$, ${17}$, ${22}$. Revise the flawed model by deciding whether one output is likely an error, replacing it, and writing a rule that fits the corrected table.

Solution: The outputs mostly increase by about $4$. A likely correction is to replace $17$ with $18$, giving $10,14,18,22$. A rule for inputs $0,1,2,3$ is $y=4x+10$.
