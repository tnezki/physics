Station 1 Answers

Question 1

In the phrase "temperature depends on time," which quantity is the input?

Solution: Time is the input because temperature depends on time.

Question 2

Does the pair list $(1,4),(2,5),(1,6)$ give one output for each input?

Solution: No. Input $1$ is paired with both $4$ and $6$, so it does not give exactly one output for each input.

Question 3

Use the graph of $f$ to estimate $f(-2)$ and the input where the output is $1$.

Solution: From the graph, $f(-2)\approx6$. The output is $1$ when the input is about $3$.

Question 4

Build a strategy for deciding whether a list of ordered pairs represents a function without graphing it. Then apply your strategy to $(0,4),(1,6),(2,8),(1,10)$.

Solution: Strategy: list each input and check whether any input repeats with a different output. In $(0,4),(1,6),(2,8),(1,10)$, input $1$ has outputs $6$ and $10$, so the relation is not a function.

Station 2 Answers

Question 5

Evaluate each expression if $r=-3$, $s=4$, and $t=2$.

  1. $r+s^2$
  2. $2t-rs$
  3. $\frac{s-r}{t}$
  4. $|r|-t^2$
Solution:
  1. $r+s^2=-3+4^2=13$.
  2. $2t-rs=2(2)-(-3)(4)=4+12=16$.
  3. $\frac{s-r}{t}=\frac{4-(-3)}{2}=\frac{7}{2}$.
  4. $|r|-t^2=3-4=-1$.

Question 6

For each input, write the substitution step before finding the value.

  1. $-2x^2-3x+1$ for $x=-3$
  2. $8-3a^2$ for $a=2$
  3. $\frac{m+5}{2}$ for $m=-1$
Solution:
  1. $-2(-3)^2-3(-3)+1=-18+9+1=-8$.
  2. $8-3(2)^2=8-12=-4$.
  3. $\frac{-1+5}{2}=2$.

Question 7

A student writes $6+2(5)^2=40$. Find the correct value and describe the operation-order mistake.

Solution: Correct value: $6+2(5)^2=6+2(25)=6+50=56$. The mistake was multiplying $2\cdot5$ before applying the exponent to $5$.

Question 8

For $h(t)=12-3t$, calculate $h(-2)$, $h(0)$, and $h(4)$. Explain what changes in the expression as $t$ increases.

Solution: $h(-2)=12-3(-2)=18$, $h(0)=12$, and $h(4)=0$. As $t$ increases by $1$, the term $-3t$ decreases the output by $3$.

Question 9

Create a sequence of steps to evaluate $\frac{5-2(3-x)}{x+1}$ for $x=4$. Your sequence must include substitution, grouping, multiplication, and division.

Solution: Substitute $x=4$: $\frac{5-2(3-4)}{4+1}$. Grouping: $3-4=-1$. Multiplication: $2(-1)=-2$. Numerator: $5-(-2)=7$. Division: $\frac{7}{5}=1.4$.

Question 10

Analyze the structure of $6x+18$. Explain what is revealed by the form $6(x+3)$ that is not as visible in the original sum.

Solution: The form $6(x+3)$ reveals a common factor of $6$ and shows the expression as six groups of $(x+3)$. The original $6x+18$ makes the separate terms visible but not the grouping.

Question 11

Construct a strategy for deciding whether $3(2x-5)+4$ and $6x-11$ are equivalent for all $x$. Your strategy must include more than testing one value.

Solution: Distribute first: $3(2x-5)+4=6x-15+4=6x-11$. Since the simplified form matches $6x-11$, the expressions are equivalent for all $x$. Testing one value can support the result but does not prove it for all values.

Question 12

Design a short classroom-supply context represented by $5+2n^2$. Define $n$, choose a reasonable value, evaluate the expression, and interpret the result.

Solution: One valid context: A teacher buys a \$5 storage bin and $2$ square packs of pencils for each of $n$ tables. For $n=4$, $5+2(4)^2=5+32=37$. The result means $37$ total items or dollars depending on the chosen context.

Question 13

A student labels the horizontal axis “number of students” and the vertical axis “class period” for a graph comparing class period to number of students. Which quantity is the input, and which is the output?

Solution: The input is the quantity placed on the horizontal axis: number of students. The output is class period on the vertical axis.

Question 14

Which point is closest to the origin: $({2},{1})$, $(-1,{3})$, or $({4},{0})$? Use coordinate distance in your explanation.

Solution: Compare squared distances from the origin: $(2,1)$ gives $2^2+1^2=5$, $(-1,3)$ gives $10$, and $(4,0)$ gives $16$. The closest point is $(2,1)$.

Question 15

Make a coordinate graph for the ordered pairs in the table, then state the vertical intercept.

$x$01234
$y$47101316
Solution: Plot the points $(0,4),(1,7),(2,10),(3,13),(4,16)$. The vertical intercept is $(0,4)$ because that is where $x=0$.

Question 16

For the outputs ${3}$, ${8}$, ${13}$, ${18}$, analyze the pattern using two methods: repeated change and a symbolic rule. Explain how both methods support the same prediction for input ${12}$.

Solution: Repeated change: the outputs increase by $5$ each step. A symbolic rule with input starting at $0$ is $y=5x+3$. For input $12$, $y=5(12)+3=63$.
