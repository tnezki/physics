Station 1 Answers

Question 1

1. What does the word rest mean when a particular reference frame has been chosen?

Answer / work: An object is at rest when its position does not change relative to the chosen reference frame.

Question 2

2. A laptop stays on a tray table while an airplane taxis. Describe the laptop relative to the tray and relative to the airport terminal.

Answer / work: Relative to the tray, the laptop is at rest. Relative to the airport terminal, it moves with the airplane.

Question 3

3. Identify the reference frame in this description: “The elevator rises past the third-floor doorway.”

Answer / work: The building, specifically the third-floor doorway, is the reference frame.

Question 6

6. A boat passenger watches a cooler stay beside the same bench while a person on a dock watches the cooler move downstream. Compare the two descriptions and name the frame used by each observer.

Answer / work: The passenger uses the boat/bench frame, so the cooler is at rest. The dock observer uses the shore/dock frame, so the cooler moves downstream with the boat.

Question 7

7. Use the Earth–Sun figure. Explain how a chair can be at rest relative to the room while still moving relative to the Sun.

Answer / work: The chair’s position does not change relative to the room, so it is at rest in the room frame. The room is on Earth, which moves relative to the Sun, so the chair also moves relative to the Sun.

Answer / work: Relative to the moving walkway, the standing traveler is at rest. Relative to the airport floor, the traveler moves in the walkway’s direction.

Question 9

9. Choose a useful reference frame for each purpose: describing a swimmer’s motion inside a moving boat, describing the boat’s motion along a river, and describing Earth’s motion in the solar system. Justify each choice briefly.

Answer / work: Use the boat as the frame for the swimmer inside the boat, the riverbank/shore for the boat moving along the river, and the Sun for Earth’s motion in the solar system. Each frame is chosen because it makes the motion of interest easy to describe.

Question 10

10. The sentence “The package moved 20 m” appears in a lab report. Explain what information about the reference frame must be stated or implied before the claim can be interpreted.

Answer / work: The report must state or imply what object or frame the package changed position relative to, such as the lab floor, a cart, or a vehicle.

Station 5 Answers

Question 11

11. Two observers report opposite answers to “Is the cart moving?” Observer A stands on the cart; Observer B stands beside the track. Explain how both answers could be correct without either observer making a measurement error.

Answer / work: Observer A is at rest with the cart, so the cart does not change position in A’s frame. Observer B is beside the track, so the cart changes position in B’s ground frame. Both descriptions can be correct.

Question 12

12. A student argues that the ground frame is always the “real” frame and any vehicle frame is wrong. Evaluate the argument and give an example showing why multiple frames can be useful.

Answer / work: The argument is incorrect. Motion is relative, so no single frame is always the “real” frame. For example, a passenger can be at rest relative to a train while moving relative to the ground; both frames are useful for different questions.

A. moving backward
B. moving forward
C. at rest
D. accelerating
E. in free fall
Answer: C — at rest
Rationale: The backpack does not change position relative to the train seat, so it is at rest in that frame.

Question 14

A. the seat cushion
B. a passenger sitting beside it
C. the train floor
D. a station platform
E. its zipper
Answer: D — a station platform
Rationale: The station platform is outside the moving train, so the backpack changes position relative to it.

C. travels far
D. changes position
E. moves for ten seconds
Answer: B — is at rest relative to the dock
Rationale: The phrase “relative to the dock” explicitly names the comparison frame.

A. they use different reference frames
B. one observer is always wrong
C. the object has two masses
D. time stops
E. the object has no position
Answer: A — they use different reference frames
Rationale: Motion can differ for the same object when observers choose different reference frames.

Question 18

Question 19

19. Why does “a car travels 25 m/s” usually mean relative to the road?

A. Road motion is the conventional nearby frame.
B. Cars cannot be reference frames.
C. The road has zero motion in every frame.
D. Velocity is independent of frames.
E. The driver cannot observe motion.
Answer: A — Road motion is the conventional nearby frame.
Rationale: For ordinary road travel, the road/ground is the conventional nearby reference frame unless another frame is stated.

Question 20

20. Which situation most clearly requires stating a non-ground reference frame to avoid confusion?

A. a runner on a moving train
B. a parked bicycle beside a tree
C. a book on a desk
D. a mailbox beside a road
E. a cone on a field
Answer: A — a runner on a moving train
Rationale: A runner on a moving train can have one motion relative to the train and another relative to the ground, so the frame must be stated.
