Station 1 Answers

Question 1

1. Which term names the object, surface, or viewpoint used as the comparison for motion?

A. reference frame
B. acceleration
C. speed
D. distance
Answer: A — reference frame
Work / rationale: A reference frame is the chosen object, surface, or viewpoint used as the comparison for position and motion.

Question 2

2. A phone stays on a bus seat. Relative to the seat, the phone is

A. moving forward
B. at rest
C. moving backward
D. changing direction
Answer: B — at rest
Work / rationale: The phone keeps the same position relative to the seat, so it is at rest in the seat frame.

Question 3

3. The same phone is moving relative to

A. the seat
B. the bus floor
C. a roadside sign
D. a passenger beside it
Answer: C — a roadside sign
Work / rationale: The bus carries the phone past the roadside sign, so the phone changes position relative to that ground-fixed frame.
