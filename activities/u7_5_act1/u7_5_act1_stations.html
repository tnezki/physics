Station 1 Answers

Question 1

1. How many current paths does a simple series circuit have?

Answer / rationale: A simple series circuit has one current path through all components.

Question 2

2. What circuit condition is required for current to continue around a loop?

Answer / rationale: The loop must be closed/complete so charge has an unbroken conducting path around the circuit.

Question 3

3. In a branched circuit, where does current split and where does it recombine?

Answer / rationale: Current splits at a junction where branches separate and recombines at a junction where those branches meet again.

Question 6

6. Use the parallel-circuit figure to identify the separate current paths and explain why one branch can remain complete if another branch opens.

Answer / rationale: The figure shows separate branches connected between the same two supply nodes. Each branch has its own complete path, so opening one branch interrupts only that path; charge can still flow through the other intact branches.

Question 7

7. A sensor box contains a 5 Ω resistor followed by an 11 Ω resistor in the same single path. Find the resistance the source sees from those two components together.

Work: Series resistances add: $R_{eq}=5\ \Omega+11\ \Omega=16\ \Omega$. Answer: $16\ \Omega$.

Station 4 Answers

Question 8

8. Two identical 9 Ω heating elements connect across the same two nodes. Calculate the equivalent resistance of the pair.

Work: For two identical 9 $\Omega$ resistors in parallel, $R_{eq}=R/2=9/2=4.5\ \Omega$. Answer: $4.5\ \Omega$.

Question 9

9. A circuit has 2 A in one branch and 0.8 A in another. Calculate the total current in the common line.

Work: Main-line current equals the sum of branch currents: $I_{total}=2.0+0.8=2.8\text{ A}$. Answer: $2.8\text{ A}$.

Question 10

10. A 9 V battery supplies two ideal parallel branches. One branch is opened. Explain what happens to the voltage across the remaining intact branch.

Answer / rationale: The remaining intact branch is still connected across the same two ideal source nodes, so its voltage remains 9 V. Opening another parallel branch changes total current, not the ideal source voltage across the intact branch.

Station 5 Answers

Question 11

11. A classmate says current is used up by the first bulb in a series loop, so less current must reach the second. Critique using steady-state charge conservation and energy transfer.

Answer / rationale: In a one-path series loop at steady state, the same current passes every component because charge does not accumulate indefinitely at any point. Bulbs transfer electrical energy; they do not consume charge or current.

Question 12

12. A circuit designer wants each lamp to keep working if another lamp fails open. Compare series and parallel topologies and defend the better design.

Answer / rationale: Parallel is the better topology. Each lamp has its own complete branch, so an open failure in one lamp does not break the conducting path through the others; a series failure opens the only path for all lamps.

B. 24 Ω

D. 3 Ω
E. 6 Ω
Answer: E — 6 Ω
Work / rationale: Two identical resistors in parallel have half the single resistance: $12/2=6\ \Omega$.

Question 17

17. In a one-path series loop at steady state, which statement about current is correct?

A. Current is divided at every resistor.
B. Current is largest at the battery and zero after the first bulb.
C. The same current passes each component.
D. Each component receives the full source current plus extra.
E. Current equals voltage numerically.
Answer: C — The same current passes each component.
Work / rationale: In a steady one-path loop, charge conservation requires the same current through every component.

Question 18

Work / rationale: An intact parallel branch remains across the source nodes, so its voltage stays equal to the source voltage.

Question 20

20. A breaker trips after several high-power appliances are turned on. Which explanation is most accurate?

A. The appliances create extra voltage.
B. The added parallel loads increase total source current; excessive current can overheat wiring, so the breaker opens the common path.
C. The breaker stores extra electrons.
D. Parallel loads always raise equivalent resistance.
E. The breaker acts by shorting the source.
Answer: B — The added parallel loads increase total source current; excessive current can overheat wiring, so the breaker opens the common path.
Work / rationale: Adding parallel loads can increase total source current; excessive current heats wiring, so a breaker opens the common supply path for protection.
