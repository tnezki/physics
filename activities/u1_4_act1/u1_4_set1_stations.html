Station 1 Answers

Question 1

Simplify $4x+3x$.

Solution: $4x+3x=7x$.

Question 2

Evaluate $2x+5$ when $x=6$.

Solution: $2(6)+5=12+5=17$.

Question 3

Use substitution to decide whether $3(x+4)$ and $3x+12$ are equivalent for $x=5$ and $x=-2$.

Solution: For $x=5$: $3(5+4)=27$ and $3(5)+12=27$. For $x=-2$: $3(-2+4)=6$ and $3(-2)+12=6$. They match for both checks, and by distribution they are equivalent for all $x$.

Question 4

Compare the expression $6n+4$ with the context: a club pays a \$6 one-time fee and \$4 per member. Does the expression match the context? Use the meaning of each term to justify your answer.

Solution: The expression does not match the context. A \$6 one-time fee and \$4 per member should be $4n+6$. In $6n+4$, the $6$ is attached to $n$, so it would mean \$6 per member plus a \$4 fee.

Question 5

Sort the terms into constants and variable terms: $8x$, $-3$, $4y$, $12$, $-x$, $0.5y$.

Solution: Variable terms: $8x,4y,-x,0.5y$. Constants: $-3,12$.

Question 6

Simplify: $7a-2b+3a+9b-4$.

Solution: $7a+3a=10a$ and $-2b+9b=7b$, so the simplified expression is $10a+7b-4$.

Question 7

Solve $2.5x-4=11$ and describe why the decimal coefficient does not change the balance reasoning.

Solution: $2.5x-4=11$ gives $2.5x=15$, so $x=6$. A decimal coefficient still means undo multiplication by dividing both sides by the same number.

Question 8

Solve $2x+5\le 17$ and graph the solution set.

Solution: $2x+5\le17$ gives $2x\le12$, so $x\le6$. Graph with a closed dot at $6$ and shade left.

Station 3 Answers

Question 9

For $-4m+3\gt 19$, first predict whether solving will reverse the inequality direction. Then solve, graph the solution set, and explain the direction change.

Solution: Solving will reverse the inequality because you divide by a negative. $-4m+3\gt19$ gives $-4m\gt16$, so $m\lt-4$. Graph with an open dot at $-4$ and shade left.

Question 10

Construct a step-by-step strategy for evaluating $\left|-4.5+\frac{7}{3}\right|-\left(-\frac{5}{6}\right)$. Your strategy must explain when to use absolute value and when to combine rational numbers.

Solution: Combine inside the absolute value first: $-4.5+\frac{7}{3}=-\frac{13}{6}$. Absolute value gives $\frac{13}{6}$. Then subtracting $-\frac{5}{6}$ means add: $\frac{13}{6}+\frac{5}{6}=3$.

Question 11

The expression $2x+5$ is represented by the table. One table entry is wrong. Identify the first mismatch, correct it, and explain how you know.

$x$$0$$1$$2$$3$
$2x+5$$5$$7$$8$$11$
Solution: For $2x+5$, the outputs should be $5,7,9,11$. The mismatch is $8$ at $x=2$; it should be $9$.

Question 12

Two students model a reading goal. Student A uses $p\ge 20$ pages per day; Student B uses $7p\ge 140$. Recommend which model is better for planning a week of reading and explain the tradeoff.

Solution: Student B’s model $7p\ge140$ is better for planning a whole week because it connects daily pages to the weekly total. Solving gives $p\ge20$, the same daily requirement as Student A. Student A is simpler; Student B shows why the weekly goal is met.

Station 4 Answers

Question 13

Find the input that gives output ${15}$ for the rule $y=x+9$.

Solution: $15=x+9$, so $x=6$.

Question 14

State whether $({4},{17})$ fits the rule $y={4}x+1$.

Solution: For $x=4$, $4x+1=4(4)+1=17$, so $(4,17)$ fits the rule.

Question 15

A student wrote $y=x+4$ for a table where inputs ${1}$, ${2}$, ${3}$ have outputs ${6}$, ${8}$, ${10}$. Write the correct rule and explain the repeated change.

Solution: The outputs increase by $2$, so the rate is $2$. Using input $1$ and output $6$, $6=2(1)+b$, so $b=4$. The correct rule is $y=2x+4$.

Question 16

A student writes $y={4}x+5$ for a pattern with ${4}$ tiles in Figure ${0}$ and ${5}$ more tiles each figure. Critique the equation and write the correct one.

Solution: The equation reverses the starting value and rate. Figure $0$ has $4$ tiles, so the starting value is $4$. The pattern grows by $5$ tiles each figure, so the correct equation is $y=5x+4$.
