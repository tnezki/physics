Set 2 — Station 3 Solutions

Problem 3

Classify each as a possible equilibrium state: a hanging sign at rest; a train moving straight at constant speed; a cyclist speeding up.

Solution: The at-rest case can be static equilibrium; the straight constant-velocity case can be dynamic equilibrium; the changing-speed/direction case is not equilibrium because velocity changes.
Problem 4

A sign hangs at rest; a train travels straight at constant velocity. Which is static equilibrium and which is dynamic equilibrium?

Solution: The motionless object is static equilibrium; the object moving straight at constant velocity is dynamic equilibrium.

Set 2 — Station 4 Solutions

Problem 1

A laptop is at rest. Explain why forces do not disappear just because it is motionless.

Solution: Nonzero forces still act (including weight and a support/tension force from the desk); at equilibrium they balance to zero net force.
Problem 2

A resting object has 75 N downward weight. Which vertical force model is consistent with equilibrium?

Solution: An upward support/tension force of 75 N together with 75 N downward weight.

Solution: Upward.

Set 2 — Station 5 Solutions

Problem 1

Use the force model to decide whether the object is in equilibrium. Explain by direction.

Solution: Horizontal net = +0 N (right positive); vertical net = -4 N (up positive). Because at least one component is nonzero, the object is not in equilibrium.
Problem 2

A satellite moves in a circular path at constant speed. Explain why constant speed alone does not prove equilibrium.

Solution: Direction changes, so velocity changes. A change in velocity requires nonzero net force; therefore the motion is not equilibrium.

Problem 3

A student labels a resting object “equilibrium” but draws 50 N upward and 35 N downward. Critique the diagram.

Solution: Unequal vertical forces give a nonzero net force, so the diagram is inconsistent with equilibrium. For vertical equilibrium the upward and downward totals must be equal.
Problem 4

A sled moves straight at constant speed while 9 N acts left and 9 N acts right. Connect the force balance to the motion.

Solution: The horizontal net force is zero, so the velocity does not change; straight constant-speed motion is consistent with dynamic equilibrium.
