Station 1 Answers

Question 1

Use the distributive property to rewrite $3(x+2)$.

Solution: $3(x+2)=3x+6$.

Question 2

Use the diamond to find two numbers with product $-24$ and sum $2$. Then write a related factored form for $x^2+2x-24$.

Solution: The numbers are $6$ and $-4$ because $6(-4)=-24$ and $6+(-4)=2$. Therefore $x^2+2x-24=(x+6)(x-4)$.

Question 3

A student simplified $5(2x-3)+4x$ as $10x-15+4=10x-11$. Critique the error and revise the simplification.

Solution: The student distributed correctly to get $10x-15$, but then treated $4x$ as $4$. The correct simplification is $10x-15+4x=14x-15$.

Question 4

Create a real context that can be represented by both $8x+20$ and $4(2x+5)$. Then explain what each form reveals about the situation and give one input-output check that confirms equivalence.

Solution: Example context: Four identical supply kits each contain $2x+5$ items. The form $4(2x+5)$ shows $4$ groups; the form $8x+20$ shows the total variable items and constants after distributing. For $x=3$, both give $4(11)=44$ and $24+20=44$.

Station 2 Answers

Question 5

Choose the property used in $6(x+2)=6x+12$: commutative, distributive, or inverse. Explain in one sentence.

Solution: The property is the distributive property because $6$ is multiplied by both $x$ and $2$.

Question 6

Fill in the blank to make an equivalent expression: $9m+15=3(\square+5)$.

Solution: $9m+15=3(3m+5)$, so the blank is $3m$.

Question 7

Solve each equation.

  1. $x+5=5$
  2. $3x+1=43$
  3. $-2x-3=3$
Solution:
  1. $x+5=5$ gives $x=0$.
  2. $3x+1=43$ gives $3x=42$, so $x=14$.
  3. $-2x-3=3$ gives $-2x=6$, so $x=-3$.

Question 8

A club needs at least $30$ volunteers. It already has $12$ volunteers and gains $v$ more. Write, solve, and interpret an inequality for $v$.

Solution: Inequality: $12+v\ge30$. Subtract $12$ to get $v\ge18$. The club needs at least $18$ more volunteers.

Station 3 Answers

Question 9

A machine can run no more than $45$ minutes. It has already run $18$ minutes. Use an inequality to determine the greatest additional number of minutes it can run.

Solution: Let $m$ be additional minutes. $18+m\le45$, so $m\le27$. The greatest additional time is $27$ minutes.

Question 10

Graph the compound inequality $-2\lt x\le5$. Then test $x=-2$, $x=5$, and $x=6$ in the inequality to justify which endpoints and outside values are included or excluded.

Solution: Graph $-2\lt x\le5$ with an open dot at $-2$, a closed dot at $5$, and shading between. $x=-2$ is excluded because it makes $-2\lt-2$ false. $x=5$ is included. $x=6$ is outside because $6\le5$ is false.

Question 11

Analyze the structure of $4(3+x)^2$. Explain why squaring must happen before multiplying by $4$, and describe a different expression that would mean "multiply $3+x$ by $4$, then square."

Solution: In $4(3+x)^2$, order of operations says evaluate the parentheses, square that quantity, then multiply by $4$. To mean “multiply $3+x$ by $4$, then square,” write $[4(3+x)]^2$.

Question 12

A class has two possible project rules: $h\le 4$ hours or $2h+1\le 9$. Recommend which rule is clearer for students and justify by solving both.

Solution: Solve $2h+1\le9$: $2h\le8$, so $h\le4$. Both rules are equivalent. The rule $h\le4$ is clearer for students because it states the maximum hours directly; $2h+1\le9$ may show a scoring or workload model.

Station 4 Answers

Question 13

Complete the table for $y=x^2+1$.

$x$0123
$y$12?10
Solution: For $x=2$, $y=2^2+1=5$. The missing table value is $5$.

Question 14

Create a verbal rule that matches $y={5}x-1$, then find the output when $x={8}$.

Solution: Verbal rule: multiply the input by $5$, then subtract $1$. For $x=8$, $y=5(8)-1=39$.

Question 15

The equation and table are supposed to represent the same relationship. Find the mismatch, explain how you know, and revise the incorrect value.

Equation: $y={3}x+4$

$x$01234
$y$47101416
Solution: Use $y=3x+4$. For $x=0,1,2,3,4$, outputs should be $4,7,10,13,16$. The mismatch is at $x=3$, where the table shows $14$ but should show $13$.

Question 16

Synthesize a linear relationship for a school fundraiser using a context, table, graph, and equation. Your model must have a nonzero starting value and a positive rate of change. Explain how each representation shows the same starting value and rate.

Solution: One valid fundraiser: the club starts with $20$ dollars and earns $5$ dollars per ticket. Equation: $y=5x+20$. Table: $(0,20),(1,25),(2,30),(3,35)$. The graph has intercept $20$ and rises by $5$ each ticket, matching the context and table.
