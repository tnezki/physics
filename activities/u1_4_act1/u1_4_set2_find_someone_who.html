Problem 9

What term best describes this example? A 20 N force right and a 20 N force left give zero net force.

Answer: balanced forces

Problem 10

Describe one situation that correctly shows constant velocity.

Answer: A puck moves east at 3 m/s without changing speed or direction.

Problem 11

Classify each as a possible equilibrium state: a hanging sign at rest; a train moving straight at constant speed; a cyclist speeding up.

Answer: The at-rest case can be static equilibrium; the straight constant-velocity case can be dynamic equilibrium; the changing-speed/direction case is not equilibrium because velocity changes.

Problem 12

A sign hangs at rest; a train travels straight at constant velocity. Which is static equilibrium and which is dynamic equilibrium?

Answer: The motionless object is static equilibrium; the object moving straight at constant velocity is dynamic equilibrium.

Problem 13

A laptop is at rest. Explain why forces do not disappear just because it is motionless.

Answer: Nonzero forces still act (including weight and a support/tension force from the desk); at equilibrium they balance to zero net force.

Problem 14

A resting object has 75 N downward weight. Which vertical force model is consistent with equilibrium?

Answer: An upward support/tension force of 75 N together with 75 N downward weight.

Problem 15

A hanging object has 140 N downward weight. What direction must an additional force act to help produce vertical equilibrium?

Answer: Upward.

Problem 16

For a cart moving straight at constant speed, what does ΣF = 0 mean physically? Does it mean no individual forces act?

Relationship: ΣF = 0

Answer: It means the vector sum of the forces is zero. Individual forces may be nonzero and balanced.

Problem 17

Use the force model to decide whether the object is in equilibrium. Explain by direction.

Answer: Horizontal net = +0 N (right positive); vertical net = -4 N (up positive). Because at least one component is nonzero, the object is not in equilibrium.

Problem 18

A satellite moves in a circular path at constant speed. Explain why constant speed alone does not prove equilibrium.

Answer: Direction changes, so velocity changes. A change in velocity requires nonzero net force; therefore the motion is not equilibrium.

Problem 19

A student labels a resting object “equilibrium” but draws 50 N upward and 35 N downward. Critique the diagram.

Answer: Unequal vertical forces give a nonzero net force, so the diagram is inconsistent with equilibrium. For vertical equilibrium the upward and downward totals must be equal.

Problem 20

A sled moves straight at constant speed while 9 N acts left and 9 N acts right. Connect the force balance to the motion.

Answer: The horizontal net force is zero, so the velocity does not change; straight constant-speed motion is consistent with dynamic equilibrium.

Problem 21

A 125 N lamp hangs motionless. Using ΣF = 0 vertically, determine the upward cable force.

Answer: 125 N upward.

Problem 22

A crate is pulled 35 N right and must remain in horizontal equilibrium. What friction force is required?

Answer: 35 N left.

Problem 23

Use the force table to verify equilibrium in each direction.

Forces on the object
ForceMagnitude/direction
support72 N up
weight72 N down
pull18 N right
friction18 N left

Answer: Vertical net = 0 N and horizontal net = 0 N, so the object is in equilibrium.

Problem 24

A sign has 85 N downward weight and an unknown upward cable force. First infer the cable force needed for equilibrium. Then a 15 N downward decoration is added; what new upward cable force is required?

Answer: First 85 N upward. After adding 15 N downward, total downward force is 100 N, so 100 N upward is required.
