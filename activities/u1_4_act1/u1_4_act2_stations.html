  1. 65 N

Answer: B — 130 N
Work / rationale: At rest, ΣF = 0, so cable tension must balance the 130 N weight: T = 130 N.

Question 8

8. A 50-kg person stands on a scale. Use $g=10\,\text{N/kg}$. Support force?

  1. 50 N
  2. 5 N
  3. 0 N
  4. 500 N
Answer: D — 500 N
Work / rationale: Weight is W = mg = (50 kg)(10 N/kg) = 500 N. Standing still requires an equal 500 N upward support force.

Question 9

9. A car moves straight at constant speed with 300 N forward. Backward resistance?

  1. 300 N
  2. 0 N
  3. 150 N
  4. 600 N
Answer: A — 300 N
Work / rationale: Constant straight-line speed means ΣF = 0, so 300 N backward resistance balances 300 N forward.

Question 10

10. A 600-N load has one support of 225 N. Second support?

  1. 225 N
  2. 375 N
  3. 600 N
  4. 825 N
Answer: B — 375 N
Work / rationale: The supports must total 600 N: 600 N − 225 N = 375 N.
