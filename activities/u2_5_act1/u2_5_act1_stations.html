Station 1 Answers

Question 1

1. In a scaled velocity-vector diagram, what does magnitude mean?

Answer / work: Magnitude is the size of the velocity represented by the arrow length according to the diagram’s scale; for velocity, it corresponds to speed.

Question 2

2. What must be true for two velocity vectors to represent exactly the same velocity?

Answer / work: They must have the same magnitude and the same direction.

Question 3

3. A motion diagram uses positions marked every second. What pattern would represent slowing down?

Answer / work: The gaps between successive positions get smaller over equal time intervals.

Station 3 Answers

Question 6

6. A drone’s velocity arrow changes from 4 cm east to 4 cm north using the same scale. Compare speed, direction, velocity, and acceleration.

Answer / work: The arrows have the same length, so the speed is unchanged. The direction changes from east to north, so velocity changes. A change in velocity means the drone has nonzero acceleration during the turn.

Question 7

7. A table shows distances 0, 3, 6, 9, 12 m at one-second intervals. Predict the shape of the matching distance–time graph and the motion-diagram spacing.

Answer / work: Distance increases by 3 m every second, so the distance–time graph is a straight line with constant positive slope. The motion diagram has equally spaced positions.

Question 8

8. A motion diagram’s gaps are 1 m, 3 m, 5 m, and 7 m over equal time intervals. Describe the motion and explain what a matching distance–time graph should do.

Answer / work: The increasing gaps show the object is speeding up. A matching distance–time graph should become progressively steeper as time increases.

Question 9

9. Use the distance–time graph. Describe the motion shown by the changing slope and state what dot-spacing trend should match it.

Answer / work: The graph’s slope increases with time, so the object is speeding up. A matching equal-time motion diagram should have gaps that increase from dot to dot.

Question 10

10. A student labels two same-length, opposite-direction arrows as “same velocity.” Explain the error and rewrite the claim correctly.

Answer / work: Same length means the vectors have the same speed, not the same velocity. Correct claim: the objects have equal speeds but opposite velocities because their directions are opposite.

Question 11

11. A table shows equal distance increases each second, but a graph drawn from it curves upward. Critique the graph and describe the corrected graph shape.

Answer / work: The graph is inconsistent with the table. Equal distance increases in equal time intervals require a straight distance–time line with constant slope, not an upward-curving line.

Question 12

12. A classmate says, “If the vectors have the same length, the motion model is consistent.” Evaluate the statement using an example in which direction changes.

Answer / work: The statement is incorrect because equal vector lengths only show equal speed. For example, equal-length east and north velocity vectors have the same speed but different velocities; changing direction also means acceleration is nonzero.

Question 14

14. Two vectors match exactly when they have

A. the same scaled length and direction
B. the same color
C. the same length only
D. the same direction only
E. different scales
Answer: A — the same scaled length and direction
Rationale: Two vectors represent the same velocity only when both their scaled lengths and directions match.

Question 15

15. Equal-length arrows that rotate from east to north show

A. constant speed and changing velocity
B. changing speed and constant velocity
C. zero acceleration
D. no direction change
E. constant position
Answer: A — constant speed and changing velocity
Rationale: Equal arrow lengths show constant speed, but rotating the arrow changes direction and therefore changes velocity.

Question 16

16. Which feature should be checked to decide whether velocity changes?

A. both arrow length and direction
B. arrow color only
C. graph title only
D. object mass only
E. time units only
Answer: A — both arrow length and direction
Rationale: Velocity can change through magnitude or direction, so both arrow length and arrow direction must be checked.

Question 17

17. In an equal-time motion diagram, gaps that become smaller indicate

A. slowing down
B. speeding up
C. constant speed
D. no time intervals
E. constant velocity automatically
Answer: A — slowing down
Rationale: Smaller gaps over equal time intervals mean less distance is covered each interval, so the object is slowing down.

Question 18

18. A straight distance–time line with constant slope is evidence of

A. constant speed
B. increasing speed
C. decreasing speed
D. changing time scale
E. no motion in every case
Answer: A — constant speed
Rationale: A straight distance–time line with constant slope represents equal distance gains in equal times: constant speed.

Question 19

19. If a table gives equal distance increases but the graph curves upward, which part is inconsistent?

A. the graph
B. the table
C. both are necessarily correct
D. the time units only
E. the object name
Answer: A — the graph
Rationale: Equal distance gains require constant slope; an upward-curving graph would incorrectly show increasing speed.

Question 20

20. A strong model critique should

A. identify the mismatch, cite evidence, and propose a revision
B. only say “wrong”
C. ignore the evidence
D. replace all representations
E. focus on appearance
Answer: A — identify the mismatch, cite evidence, and propose a revision
Rationale: A strong critique identifies the mismatch, cites the evidence, and proposes a correction rather than only saying the model is wrong.
