C. distance only
D. acceleration only

A. direction
B. speed magnitude

D. mass

A. the same length only
B. the same direction only
C. the same length and direction
D. the same color

4. Equal dot spacing at equal time intervals represents

A. speeding up
B. slowing down
C. changing interval length
D. constant speed

5. Growing dot spacing represents

A. increasing speed
B. constant speed
C. decreasing speed
D. zero velocity

6. Two equal-length arrows point east then north. What changed?

A. speed magnitude
B. velocity direction
C. time interval only
D. nothing

A. direction only
B. nothing
C. speed magnitude and velocity
D. reference frame only

8. A table shows equal distance gains each second. Which graph should match?

A. an upward-curving line
B. a downward-curving line

D. a straight distance–time line with constant slope

9. A distance–time graph becomes steeper. Which motion diagram best matches?

A. dot gaps increase over time

C. dot gaps shrink

A. the diagram proves constant speed
B. the representations disagree
C. the story and diagram are automatically equivalent

B. Direction never matters in velocity.

B. remove the time column
C. keep both because models need not agree

A. greater speed
B. smaller speed
C. same speed
D. only a direction change

14. A resultant vector represents

A. only the larger component
B. the combined effect of component velocities

D. elapsed time

A. speeding up
B. constant speed
C. slowing down
D. constant acceleration necessarily

B. the diagram uses arrows
C. the graph has axes

17. Which representations should be checked together when evaluating a motion model?

A. graph, table, diagram, and story
B. only the title
C. only the picture color
D. only the object mass

18. A strong model critique includes

A. only a verdict
B. specific evidence and a revision
C. no reference to data
D. a new unrelated scenario

19. A table increases 0, 3, 6, 9 m each second. Which description fits?

A. speeding up
B. slowing down
C. constant speed
D. changing direction is guaranteed

A. velocity is constant
B. acceleration must be zero
C. direction is irrelevant
