Question 1

1. A velocity vector communicates

A. magnitude and direction
B. mass and time
C. distance only
D. acceleration only
Answer: A — magnitude and direction
Work / rationale: Velocity is a vector, so a complete velocity vector communicates both magnitude and direction.

Question 2

2. In a scaled vector, arrow length represents

A. direction
B. speed magnitude
C. elapsed time
D. mass
Answer: B — speed magnitude
Work / rationale: With a fixed scale, vector length encodes the velocity magnitude (speed).

Question 3

3. Two velocity vectors are identical only if they have

A. the same length only
B. the same direction only
C. the same length and direction
D. the same color
Answer: C — the same length and direction
Work / rationale: Identical vectors must match in both scaled length and direction.
