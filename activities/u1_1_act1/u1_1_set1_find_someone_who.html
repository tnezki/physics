A motion sensor reads 0.72 m/s. A student says, “The cart is speeding up because the battery is strong.” Identify the direct observation and the inference.

Match these scientific roles to their jobs: hypothesis, law, theory, inference. Identify which is a testable proposed explanation, a pattern description, a broad explanation, and a conclusion drawn from observations.

Answer: Hypothesis = testable proposed explanation; law = pattern description; theory = broad evidence-based explanation; inference = conclusion from observations.

Problem 13

Is the claim “A darker surface heats faster in sunlight.” scientifically testable as written? Explain briefly.

Answer: Yes. Surface color and temperature change can be measured.

Problem 14

A student claims a rougher surface increases friction. What measurement would you need to test the claim fairly?

Answer: Measure the force needed to start or maintain sliding under matched conditions on the different surfaces.

Problem 17

The relationship average speed = distance / time is used for a marble. What does each quantity represent physically?

Relationship: average speed = distance / time

Answer: Average speed describes how much distance is covered per unit time; distance is the path length traveled; time is the elapsed duration.

Problem 18

A model predicts that increasing ramp height increases cart speed. The measured fact is that the cart travels 3.1 m. Separate the measurement from the interpretation.

Answer: The 3.1 m value is an observation/measurement; the claim about ramp height causing greater speed is an interpretation/model inference.

Problem 19

Compare these claims: “A longer rubber band stretch launches the cart farther.” and “The cart travels farther because it wants to use all its stored energy.” Which is more scientifically testable as written, and why?

Answer: The first claim is more testable because it identifies quantities that can be observed or measured. The second uses vague/non-operational language.

Problem 20

A model predicts a longer spring should stretch more under the same added load. Name one measurement that would support or challenge this prediction.

Answer: Measure spring length or extension for different loads under controlled conditions and compare the results.

Problem 21

A small cart travels 7.5 m in 3 s. Using average speed = distance/time, determine its average speed and interpret the result.

Relationship: average speed = distance / time

Answer: 2.5 m/s. The cart covers an average of 2.5 meters each second.

Problem 22

A robot moves with an average speed of 2.4 m/s for 5 s. Using average speed = distance/time, determine the distance traveled.

Relationship: average speed = distance / time

Answer: distance = speed × time = 2.4 × 5 = 12 m.

Problem 24
