Find Someone Who — Set 2 — Section 1.1: Thinking Like a Physicist

1. Which statement is an observation?

  1. The ruler reads 31.4 cm.
  2. The object is longer because it expanded.
  3. The object will keep expanding.
  4. A theory explains the expansion.

2. Which term means a conclusion built from observations and evidence?

  1. measurement
  2. inference
  3. scientific law
  4. model

3. Which term is a proposed explanation or prediction that can be tested?

  1. observation
  2. measurement
  3. hypothesis
  4. scientific law

4. Which term describes a broad explanation supported by a large body of well-tested information?

  1. inference
  2. measurement
  3. testable claim
  4. scientific theory

5. Which term describes a simplified representation used to explain or predict a physical situation?

  1. model
  2. law
  3. observation
  4. evidence

6. A student records that a shadow is 12 cm long and concludes the light source is not directly overhead. Which part is the inference?

  1. The shadow exists.
  2. The light source is not directly overhead.
  3. The shadow is 12 cm long.
  4. The ruler has centimeter marks.

7. Why can a simplified model still be scientifically useful?

  1. It looks exactly like reality.
  2. It guarantees every prediction will be correct.
  3. It can preserve the relationships important to the question even if some details are omitted.
  4. It removes the need for measurements.

8. Which claim is most testable?

  1. A hidden cause changes motion but can never be detected.
  2. Nature prefers this result.
  3. The result occurs for an unknowable reason.
  4. A cart released from a higher ramp position travels farther on the same floor.

9. Repeated measurements disagree with a model’s prediction. What is the best response?

  1. Check the measurements and assumptions, then revise the model if the disagreement remains.
  2. Ignore the measurements.
  3. Keep the model unchanged because it came first.
  4. Change the data to fit the model.

10. Why should a student identify what each symbol in a formula represents before calculating?

  1. To make the calculator work faster.
  2. To connect the mathematical relationship to the measured physical quantities and assumptions.
  3. To guarantee the measurements are exact.
  4. To avoid interpreting the result.

11. A precise calculation is based on a poorly estimated distance. Which evaluation is strongest?

  1. The answer must be correct because the arithmetic is precise.
  2. The estimate becomes exact inside a formula.
  3. The result may not be well supported because the input evidence is weak.
  4. Only the number of decimal places matters.

12. Model A is visually realistic but fails to predict new measurements. Model B is simpler but correctly predicts them. Which evaluation is best?

  1. Model A is better because it has more detail.
  2. Both models are equally strong because all models are simplified.
  3. Neither model can be evaluated with evidence.
  4. Model B is more useful for this question because its preserved relationship fits the evidence.

13. Which choice is an inference rather than an observation?

  1. The spacing in the photo suggests the object is speeding up.
  2. The timer reads 3.8 s.
  3. The scale reads 210 g.
  4. The mark is 6 mm wide.

14. Which pair correctly matches the terms?

  1. Observation—untestable idea; inference—measuring tool.
  2. Observation—directly recorded; inference—conclusion built from evidence.
  3. Observation—broad theory; inference—scientific law.
  4. Observation—model; inference—formula.

15. Why must a scientific claim be testable?

  1. So it will always be true.
  2. So it never needs revision.
  3. So evidence could support or challenge it.
  4. So authority can decide the result.

16. Which result would provide the strongest challenge to a claim?

  1. A classmate dislikes the claim.
  2. The claim uses a short equation.
  3. The claim was proposed recently.
  4. A careful repeatable measurement that contradicts its prediction.

17. A model predicts equal ratios in repeated trials. Which evidence best supports it?

  1. Several independent trials give nearly the same expected ratio.
  2. One trial gives the expected ratio.
  3. The diagram is attractive.
  4. The model was made by an expert.

18. Which action best evaluates whether an explanation is supported?

  1. Count how many scientific words it uses.
  2. Compare its predictions with observations and measurements.
  3. Choose the oldest explanation.
  4. Reject any unexpected result immediately.

19. Which statement best describes a formula in physics?

  1. A replacement for evidence.
  2. A guarantee that assumptions are correct.
  3. A compact model showing how quantities relate.
  4. A rule that makes estimates exact.

20. A formula gives a result that conflicts with careful measurements. What should a physicist do first?

  1. Keep the formula result because equations cannot be wrong.
  2. Discard the measurements without checking them.
  3. Add more decimal places to the calculation.
  4. Check the measurements, assumptions, and whether the formula applies to the situation.
