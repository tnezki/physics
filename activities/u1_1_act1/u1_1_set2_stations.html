Set 2 — Station 5 Solutions

Problem 1

The relationship average speed = distance / time is used for a toy truck. What does each quantity represent physically?

Relationship: average speed = distance / time
Solution: Average speed describes how much distance is covered per unit time; distance is the path length traveled; time is the elapsed duration.
Problem 2

A model predicts that a longer pendulum has a longer period. A measured period is 1.6 s. Separate the measurement from the interpretation.

Solution: The 1.6 s period is a measurement; the statement that length causes the longer period is a model-based interpretation.

Set 2 — Station 5 Solutions

Problem 3

Compare these claims: “A metal rod expands measurably when its temperature increases.” and “The rod expands because warmth makes matter feel relaxed.” Which is more scientifically testable as written, and why?

Solution: The first claim is more testable because it identifies quantities that can be observed or measured. The second uses vague/non-operational language.
Problem 4

A model predicts a steeper ramp should increase the speed of a cart at the bottom. Name one measurement that would support or challenge this prediction.

Solution: Measure cart speed at the bottom for several ramp heights under controlled conditions and compare the results.

Problem 1

A small cart travels 12 m in 4 s. Using average speed = distance/time, determine its average speed and interpret the result.

Relationship: average speed = distance / time
Solution: 3 m/s. The cart covers an average of 3 meters each second.
Problem 2

A robot moves with an average speed of 1.8 m/s for 7 s. Using average speed = distance/time, determine the distance traveled.

Relationship: average speed = distance / time
Solution: distance = speed × time = 1.8 × 7 = 12.6 m.
