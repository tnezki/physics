  2. The object is longer because it expanded.

Answer: A — The ruler reads 31.4 cm.

  2. inference

  4. model
Answer: B — inference
Work / rationale: An inference is a conclusion drawn from observations and evidence.

  3. hypothesis
  4. scientific law
Answer: C — hypothesis
Work / rationale: A hypothesis is a proposed explanation or prediction that can be tested.
