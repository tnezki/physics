Problem 1

Two horizontal forces act: 18 N right and 7 N left. Predict the resultant direction before calculating.

Solution: Right, because the force in that direction is larger.
Problem 2

Use the vector diagrams to explain when one-dimensional force magnitudes should be added and when they should be subtracted.

Solution: Add magnitudes when forces point in the same direction. Subtract magnitudes when they point in opposite directions, with the resultant pointing toward the larger force.
