Question 1

1. The first step in a force model is to

  1. choose the object being modeled
  2. draw velocity
  3. add inertia
  4. calculate mass
Answer: A — choose the object being modeled
Work / rationale: A force diagram must first identify the single object whose interactions are being modeled.

Question 2

2. Each force arrow should represent

  1. motion direction
  2. a real interaction acting on the chosen object
  3. inertia
  4. the object’s path
Answer: B — a real interaction acting on the chosen object
Work / rationale: Each arrow should correspond to a real interaction force acting on the chosen object.

Question 3

3. Balanced forces mean

  1. no forces act
  2. all arrows point right
  3. net force is zero
  4. the object must be at rest
Answer: C — net force is zero
Work / rationale: Balanced forces have a vector sum of zero, even though individual forces may still be present.

Question 4

4. A nonzero net force means

  1. motion is constant
  2. no forces act
  3. mass is zero
  4. motion is changing
Answer: D — motion is changing
Work / rationale: A nonzero net force produces acceleration, so the object’s velocity is changing.

Question 5

  1. drawing an inertia force arrow
  2. drawing weight from Earth
  3. drawing support from a floor
  4. drawing tension from a rope
Answer: A — drawing an inertia force arrow
Work / rationale: Inertia is a property of matter, not an interaction force, so it should not be drawn as a force arrow.

  1. speeding up right
  2. constant straight-line motion
  3. slowing while moving right only

Answer: B — constant straight-line motion
Work / rationale: The horizontal forces cancel: 45 N right − 45 N left = 0 N, so constant straight-line motion is possible.

Answer: C — 40 N right
Work / rationale: Net force = 70 N right − 30 N left = 40 N right.
