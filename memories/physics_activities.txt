================================================================

PURPOSE
-------
THIS FILE IS THE CURRENT SINGLE SOURCE OF TRUTH FOR PHYSICS ACTIVITY BUILDS.

Each Physics section uses ONE directions shell with TWO interchangeable question sets:
- Set 1 comes from the approved Practice Set 2.
- Set 2 comes from the approved Practice Set 3.

The main activity HTML contains directions only. Question/solution decks, Stations, and Find
Someone Who worksheets are separate files so the teacher can choose either question set
without duplicating the directions.

================================================================
MULTIPLE-CHOICE LABEL STANDARD
================================================================
All multiple-choice answer choices in activity resources must DISPLAY with uppercase letters:
  A, B, C, D

Do not allow browser-default ordered lists to display choices as 1, 2, 3, 4. Preserve the
approved choice wording and order; only the visible choice labels change to letters. This rule
applies to both Set 1 and Set 2 question/solution decks, both Stations files, and both Find
Someone Who worksheets whenever a question is multiple choice.
