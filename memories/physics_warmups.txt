PHYSICS WARMUP BUILD — PORTABLE MEMORY / GOLD STANDARD
================================================================

PURPOSE
-------
This portable memory defines the gold-standard workflow for building Physics warmups.
It supersedes Algebra-specific warmup conventions. Use the uploaded Physics assessments,
assessment plan/mapping, CSS, graph tool, and current gold-standard warmup package as the
content/style references when available.

The warmup is a DAILY RETRIEVAL + ALGEBRA-LITERACY routine, not a miniature formative
assessment. Each warmup has exactly four problems with distinct jobs.

SOURCE PRIORITY
---------------
1. This portable memory.
2. User's explicit instructions in the current conversation.
3. Current unit formative and summative assessments / assessment plan.
4. Current gold-standard warmup HTML/package.
5. warmup.css and base.css.
6. graph_tool.py.
7. Saved memory / prior habits.

If an older Algebra rule conflicts with this Physics portable memory, follow this file.

================================================================
CORE FOUR-PROBLEM PATTERN
================================================================

PROBLEM 1 — BRAIN TEASER / PUZZLE
---------------------------------
Purpose: get students thinking, noticing patterns, testing possibilities, and discussing.

This problem DOES NOT need to be science or physics related.

Use a varied, nonrepeating bank across the unit. Strong choices include:
- connect-the-dots puzzles using a fixed number of straight lines
- Seven Bridges / path-tracing style puzzles
- move-one-toothpick puzzles
- rebus / picture riddles
- word-position riddles (word over/under/inside another word, etc.)
- logic puzzles
- lateral-thinking / MindTrap-style questions
- number or visual patterns
- spatial reasoning
- short constraint puzzles
- other middle-school/high-school appropriate brain teasers

HARD RULES:
- Do not repeat the same riddle/puzzle within a unit.
- Avoid near-duplicates that merely swap names/numbers.
- Rotate puzzle families intentionally.
- Draw an image whenever the puzzle is clearer visually.
- Visual puzzles are encouraged, not something to avoid.
- Use graph_tool.py for figures when it contains an appropriate figure type.
- If a needed visual cannot be made with graph_tool.py, follow the current graph-tool
  instructions rather than silently inventing an incompatible drawing method.
- Keep the puzzle solvable in a warmup time frame.
- The answer key must include the intended solution.

Before writing the unit, make a private Problem 1 inventory so each day's puzzle is unique.

================================================================

PROBLEM 2 — FORMULA READING / SUBSTITUTION / ALGEBRA
----------------------------------------------------
Purpose: practice reading a word problem, identifying quantities, matching them to variables,
substituting into a supplied formula, and solving algebraically.

The formula is GIVEN to students.

The story should NOT mechanically label every value for them. Students should determine
which information corresponds to which variable.

BAD:
  Use D = m/V. D = 483.56 g/cm^3, V = 12 cm^3. Find m.

BETTER:
  Use D = m/V. A sample has a density of 4.2 g/cm^3 and occupies 15 cm^3.
  Determine its mass.

Do not unnecessarily state a computed quantity as a given when students should identify,
calculate, or substitute it themselves.

VARY THE UNKNOWN
----------------
Do not always solve for the variable isolated on the left side.
Across the unit, ask students to solve for different variables in the formula.

FORMULA SOURCE
--------------
The formula may come from physics, science, geometry, temperature conversion, finance,
motion, or another age-appropriate context. The goal is algebraic literacy.

Students are practicing:
1. identify known values
2. identify the requested variable
3. substitute
4. rearrange when needed
5. solve
6. include appropriate units

WORDING DISTRIBUTION
--------------------
Avoid Mad-Lib question writing. Rotate sentence structure deliberately.

Across a bank/unit, target approximately:
- 1/3 STANDARD / GIVENS-FIRST
- 1/3 INVERTED / ACTION-OR-QUESTION-FIRST
- 1/3 CONTEXT-RICH / REAL-WORLD

STANDARD example:
  A crane lifts a 600 kg load upward at a constant speed of 0.50 m/s.
  Determine the power required.

INVERTED example:
  Determine the power required by a crane that lifts a 600 kg load at a
  constant upward speed of 0.50 m/s.

CONTEXT-RICH example:
  A contractor building a bridge needs a crane capable of lifting a 600 kg
  load at a constant upward speed of 0.50 m/s. Determine the required power.

Sentence structures should genuinely differ, not simply move one clause.

GENUINE MULTI-STEP PROBLEMS
---------------------------
A multi-step problem requires students to calculate, determine, or look up an intermediate
quantity that is needed in order to obtain the final requested answer.

It is NOT multi-step merely because two formulas are used and two answers are reported.

Usually there should still be ONE final requested answer.

Examples:

Density:
  A rectangular container's dimensions are given. Students first determine its volume,
  then use density = mass/volume to determine the requested density or mass.

Constant travel speed:
  Susie rides at the same speed each day. Yesterday she traveled 8 miles to school in
  30 minutes. How long will it take her to ride 11 miles to a friend's house?
  Students first determine her speed, then use it to determine the new travel time.

Temperature:
  A liquid warms by 2 degrees C each hour for 7 hours. What is the total temperature
  change in degrees F?
  Students first determine the Celsius change, then convert that change.

Use genuine multi-step problems selectively; not every Problem 2 needs to be multi-step.

================================================================

PROBLEM 3 — PRIOR PHYSICS VOCABULARY / RUNG 1–2 RETRIEVAL
----------------------------------------------------------
Purpose: retrieve previously learned Physics ideas with low-floor, quick multiple-choice
practice.

For the first section of Unit 1, use appropriate general science / prerequisite knowledge.
After that, Problem 3 should primarily draw from material taught in a PREVIOUS section,
not unreleased content.

Keep Problem 3 MOSTLY:
- vocabulary
- definitions
- concept recognition
- simple examples/nonexamples
- Rung 1
- Rung 2

Rotate vocabulary prompt direction:
- term -> definition
- definition -> term
- concept -> term
- term -> concept

Occasionally use a straightforward Rung 2 application when appropriate.

MULTIPLE-CHOICE FORMAT
----------------------
Use clean choices:

A. ...
B. ...
C. ...
D. ...

Do NOT create nested numbering such as:
1. A. ...
2. B. ...
3. C. ...

Do not label answer choices with both list numbers and letters.

Problem 3 should be quick retrieval, not a disguised DOK 3/4 reasoning task.

================================================================

PROBLEM 4 — CUMULATIVE MATH / FORMULA PRACTICE
----------------------------------------------
Purpose: cumulative algebraic/formula practice using skills and formulas students have
already encountered.

Until enough prior Physics formulas exist, Problem 4 may repeat the general Problem 2
formula-practice family using a DIFFERENT question/context.

Once formulas/quantitative skills have been introduced, Problem 4 can spiral ANY prior
section of the unit.

Rules:
- Never use material students have not encountered yet.
- Vary formulas, unknowns, contexts, and sentence structures.
- Apply the same anti-Mad-Lib standards used for Problem 2.
- Do not unnecessarily label quantities as variables in the story.
- Include genuine multi-step problems when useful.
- Multi-step still means an intermediate quantity is required for ONE final result.
- Keep the task appropriate for a short warmup.

================================================================
VOCABULARY WRITING STANDARD
================================================================

When vocabulary appears anywhere in warmups or related banks, rotate among:
- term -> definition
- definition -> term
- concept -> term
- term -> concept

Do not make every vocabulary item "Which term means...?"

================================================================
UNIT PLANNING AUDIT
================================================================

Before writing Problem 1 of the first warmup, privately plan the entire unit.

For every warmup day record:

Warmup [section-day]
  P1: puzzle family + unique prompt/figure
  P2: formula + unknown + wording type + single-step/multi-step
  P3: prior section/rung + vocabulary direction or concept type
  P4: formula/skill + unknown + wording type + single-step/multi-step
  Figure(s): yes/no and filenames
  Answer-key result

Audit the full set for:
- no repeated P1 puzzles
- strong rotation of P1 puzzle families
- approximately balanced P2/P4 wording structures
- varied unknown variables
- no unreleased content in P3/P4
- mostly Rung 1–2 P3 questions
- varied vocabulary prompt direction
- no accidental duplicate numerical problems
- genuine multi-step structure where labeled multi-step
- one final answer for multi-step problems unless there is a strong reason otherwise

================================================================
HTML / CSS FORMAT
================================================================

Build ONE HTML file for the entire unit:

unit_[#]_warmups/
  unit_[#]_warmups.html
  generate_graphs.py   only when figures are required by the graph-tool workflow
  figures/             when required

ZIP:
  unit_[#]_warmups.zip

Use exactly two external CSS links, in this order:

<link rel="stylesheet" href="../../css/base.css">
<link rel="stylesheet" href="../../css/warmup.css">

Never embed a <style> block.

Use the supplied/current warmup.css as the layout authority. Do not bring back
Algebra-specific content rules merely because the CSS originated there.

MathJax configuration must come before the CDN script and include processEscapes:

<script>
window.MathJax = {
  tex: {
    inlineMath: [['$','$']],
    displayMath: [['$$','$$']],
    processEscapes: true
  }
};
</script>
<script async src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js"></script>

Use $...$ and $$...$$ delimiters.
Escape currency dollar signs.
Use \lt and \gt inside MathJax rather than raw < and >.

================================================================
WARMUP PAGE STRUCTURE
================================================================

Each day has exactly four problems.

Problem 1:
  class="problem half first"

Problems 2–4:
  class="problem half"

Use .full only if content genuinely requires it.

Every problem contains:
- problem-title
- problem-body
- workspace

Use the current gold-standard page arrangement from the approved Unit 1 warmups.
Do not redesign the format unless the user requests a layout change.

Every new warmup day starts on a new warmup page.
The day header appears with Problem 1.

Typical header:
  Section 1.1 — Day 1

Tables, if used, must use:
  <table class="values">

Do not use table.warmup-table.

================================================================
FIGURES / GRAPH TOOL
================================================================

Images are explicitly allowed and encouraged where useful, especially for Problem 1.

Examples likely to benefit from figures:
- connect-the-dots
- toothpick puzzles
- bridge/path diagrams
- spatial puzzles
- visual patterns
- picture/rebus puzzles when typography alone is insufficient
- Physics diagrams/graphs when needed

Follow the uploaded graph_tool.py instructions as authoritative for generated figures.

General workflow:
1. Read graph_tool.py completely.
2. Check whether an existing function can make the required figure.
3. If yes, use it.
4. Copy graph_tool.py in full as generate_graphs.py.
5. Append generation calls only in the permitted append area.
6. Do not modify the authoritative graph-tool source.
7. Do not use raw matplotlib as a substitute when the tool rules prohibit it.
8. Use blank/non-answer-revealing titles.
9. Verify every generated figure referenced by HTML.

Do not avoid a strong puzzle simply because it needs an image.

================================================================
ANSWER KEY — REQUIRED
================================================================

Every completed warmup unit MUST end with a teacher answer key.

The answer key belongs at the END of the same HTML file after all student warmups.

Include answers for ALL four problems on ALL warmup days.

For Problem 1:
- give the riddle/puzzle answer
- for visual/path/toothpick puzzles, briefly describe the intended solution
- include a solution figure when that is substantially clearer than prose and the graph-tool
  workflow supports it

For Problems 2 and 4:
- give the final numerical answer with units
- include essential intermediate values for genuine multi-step problems
- enough work should be present for a teacher to verify the result quickly

For Problem 3:
- give the correct letter AND the correct term/concept, not only the letter

Example:
  1.1 Day 2
    P1: [puzzle answer]
    P2: 18.0 min
    P3: B — inertia
    P4: 42 N

The answer key should be clearly separated from student warmup pages and formatted for
teacher use.

================================================================
PHYSICS UNIT 1 GOLD-STANDARD INTERPRETATION
================================================================

The approved Unit 1 warmup development established these decisions:

1. Problem 1 is NON-CONTENT brain exercise.
   It is not a prior-knowledge Physics question.
   It should feel like a short puzzle/riddle/logic challenge.

2. Problem 2 is formula literacy.
   Formula is supplied; story values are naturally embedded.
   Students identify, substitute, rearrange, and solve.

3. Problem 3 is the easy retrieval slot.
   Keep it mostly Physics vocabulary and Rung 1–2 concepts from prior instruction.

4. Problem 4 is cumulative quantitative practice.
   Before a sufficient Physics formula history exists, it may use another general
   formula-literacy problem. Later it should spiral prior quantitative skills.

5. Problem writing must sound natural.
   Rotate standard, inverted, and context-rich forms rather than cloning one template.

6. Genuine multi-step problems have a dependency:
   intermediate result -> needed for -> final requested answer.

7. The unit ends with a complete teacher answer key.

8. Visual brain teasers are a feature, not an exception.
