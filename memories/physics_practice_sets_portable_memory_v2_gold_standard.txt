PHYSICS PRACTICE SETS BUILD — PORTABLE MEMORY v2 — GOLD STANDARD
================================================================

PURPOSE
-------
THIS FILE IS THE CURRENT SINGLE SOURCE OF TRUTH FOR PHYSICS PRACTICE-SET BUILDS.

It replaces the older Physics practice-set portable memory wherever the two conflict.
In particular, the OLD 31-family / 16-main-question / Current-Mastery-Last / exit-ticket
architecture is OBSOLETE and must NOT be revived.

The approved revised Unit 1 practice-set workflow is the gold-standard interpretation:
  • four distinct practice forms per section
  • 20 questions per practice form
  • Practice Sets 1, 2, and Extra Practice use 5 DOK 1 + 5 DOK 2 + 2 DOK 3 +
    8 five-choice multiple-choice review questions
  • Practice Set 3 contains 20 four-choice multiple-choice questions and is built for
    later Blooket use
  • Practice Set 3 is figure-free
  • a Blooket CSV mirroring Practice Set 3 is included in every section ZIP
  • non-MC questions default to ws-80
  • assessment-plan timing controls when formative/summative question families are eligible
  • when too few eligible assessment questions exist, write original questions grounded
    in the CURRENT section's I-can statements and notes rather than reaching ahead
  • figures/diagrams are purposeful, not quotas, but make a deliberate effort to include
    some in Practice Sets 1, 2, and Extra Practice when the section supports them
  • graph_tool.py is used for true supported quantitative/data graphs; Physics diagrams
    are not forced through graph functions
  • current practice_set.css is the layout authority; do not embed replacement styling

"BUILD," "CREATE," "MAKE," "GENERATE," OR "REBUILD" MEANS COMPLETE THE FULL PACKAGE.
A plan, outline, question list, partial HTML, or preview is not a completed build.

================================================================
ASSESSMENT PLAN = TIMING CONTRACT
================================================================

The assessment plan decides WHEN a formative or summative question family may be used.

Before planning a section:
  1. Identify the current section and ALL of its I-can statements.
  2. Determine which formative families have become eligible by this point in the unit.
  3. Identify summative items that use only already-taught content.
  4. Build the practice pool from those eligible sources.
  5. If there are not enough eligible questions at a required DOK, create ORIGINAL
     questions from the current section's I-can statements and notes.

HARD RULE:
Never pull in later-section Physics content merely to fill a DOK quota.

Example:
If a Section 1.1 practice set needs DOK 2 questions before later force families are
eligible, write original DOK 2 questions about Section 1.1 evidence/model/testability
ideas rather than asking students to calculate net force early.

Original questions are not a failure or a last-resort compromise. They are the correct
response when the instructional sequence does not yet provide enough eligible assessment
items.

================================================================
SOURCE ADAPTATION / REWRITE STANDARD
================================================================

Practice questions should be adaptations, not assessment copies.

Allowed adaptations include:
  • rewording
  • rearranging the information order
  • swapping numbers
  • changing the real-world context
  • changing objects/agents while preserving the Physics
  • changing representation: prose ↔ table ↔ graph ↔ diagram when valid
  • changing prompt direction
  • converting open response to multiple choice or vice versa when DOK is preserved
  • combining familiar information in a new but equivalent way

Always preserve:
  • intended concept
  • learning target / I-can alignment
  • intended DOK
  • misconception being tested
  • formula/symbol limits
  • representation skill
  • scientific correctness

Do NOT create fake parallelism by changing only names or one number.

PARALLEL-FORM RULE
------------------
Practice Set 1, Practice Set 2, Practice Set 3, and Extra Practice must be genuinely
parallel but distinct.

Across forms, vary several of:
  • wording structure
  • context
  • values
  • prompt direction
  • representation
  • question order
  • distractor set
  • evidence presented

A student should not be able to use one form as a near-identical answer key for another.

================================================================
QUESTION-WRITING STANDARDS
================================================================

NATURAL WORDING
---------------
Avoid Mad-Lib question writing.

For quantitative/problem-solving banks, use a healthy mix of:
  • standard / givens-first wording
  • inverted / action-or-question-first wording
  • context-rich real-world wording

Roughly one-third of each style is a useful target where the content supports it.
Do not mechanically force the ratio on tiny banks.

VOCABULARY VARIETY
------------------
Rotate vocabulary prompts among:
  • term → definition
  • definition → term
  • concept → term
  • term → concept

Do not make every vocabulary question "Which term means...?"

MULTI-STEP RULE
---------------
A genuine multi-step problem normally requires finding an INTERMEDIATE quantity that is
needed to obtain ONE final requested answer.

Two separate formulas producing two unrelated answers is not automatically multi-step.

Do not unnecessarily state a computed quantity as a given when students should determine
or substitute it themselves.

DOK AUTHENTICITY
----------------
DOK 1:
  recall, identify, classify, label, recognize, simple one-step use.

DOK 2:
  apply a familiar relationship, interpret a representation, compare evidence,
  use a table/graph, perform routine multi-step execution, explain a familiar relationship.

DOK 3:
  strategic reasoning, critique, defend a choice with evidence, compare competing models,
  diagnose a misconception, connect representations in a non-routine way.

Do not inflate DOK by simply adding "explain why."
Do not reduce a strategic task to recall just because it is multiple choice.

================================================================
MULTIPLE-CHOICE QUALITY
================================================================

For all MC items:
  • one clearly best answer
  • distractors should be plausible and tied to real misconceptions/errors
  • avoid joke/absurd distractors
  • keep choices grammatically parallel when possible
  • avoid giving the answer away through length, specificity, units, or wording
  • do not use figures that reveal the requested classification/label

Practice Sets 1, 2, Extra:
  Q13–Q20 = 5 choices each.

Practice Set 3:
  Q1–Q20 = 4 choices each.

Correct-answer positions should be distributed intentionally.

WORKSPACE STANDARD
================================================================

DEFAULT:
  every NON-MULTIPLE-CHOICE question → <div class="workspace ws-80"></div>
  multiple-choice question            → <div class="workspace ws-10"></div>

ws-80 is the default even for DOK 3 unless the particular task clearly needs more room.

Increase workspace only when genuinely necessary, such as:
  • large calculation setup
  • student-drawn graph
  • diagram/model construction
  • multi-part strategic response
  • unusually long evidence-based explanation

Do not mechanically use larger workspace merely because the DOK number is higher.

FIGURES / DIAGRAMS / GRAPH TOOL
================================================================

VISUAL PHILOSOPHY
-----------------
Graphs and diagrams are instructional tools, not quotas.

However, do NOT avoid visuals simply because text-only questions are faster to write.
For Practice Sets 1, 2, and Extra Practice, make a deliberate figure pass and try to include
some purposeful visuals when the section supports them.

Practice Set 3 is ALWAYS figure-free under the current Blooket standard.

Good visual uses include:
  • data tables or bar/scatter/context graphs students must interpret
  • force/vector diagrams when already taught
  • source-grounded textbook diagrams or images
  • comparison figures
  • unlabeled or partially labeled models for identification/critique
  • measurement/evidence displays

A visual must add useful representation practice, not decoration.

VISUAL ANSWER-SAFETY — HARD RULE
--------------------------------
Never include an answer-revealing title, caption, legend, label, alt text, or annotation
when the student is supposed to identify, classify, label, critique, or infer that feature.

Before accepting a figure, ask:
  1. What is directly observable?
  2. What must be calculated or inferred?
  3. Does the prompt ask for something the representation actually supports?
  4. Does any text on the figure reveal the answer?
  5. Do the expected answer and the visual agree?

GRAPH TOOL — USE FOR TRUE SUPPORTED GRAPHS
------------------------------------------
The uploaded graph_tool.py is authoritative.

Workflow:
  1. Read graph_tool.py completely.
  2. Decide whether an existing graph type genuinely fits the needed representation.
  3. If yes, copy graph_tool.py IN FULL as generate_graphs.py.
  4. Do not modify, refactor, delete, restyle, or insert into the authoritative source.
  5. Append graph-generation calls only after the final permitted append marker.
  6. Run generate_graphs.py during QA.
  7. Inspect every generated graph used by the HTML.
  8. Package every referenced PNG in figures/.
  9. Package generate_graphs.py as well.

Do not use raw ad-hoc matplotlib styling to imitate a supported graph type.

PHYSICS DIAGRAMS ARE NOT AUTOMATICALLY GRAPHS
----------------------------------------------
Do NOT force these through a coordinate-graph function:
  • force diagrams
  • motion-dot diagrams
  • hanging/support-force sketches
  • circuits
  • wave schematics
  • rays
  • field lines
  • generic object/arrow models

For these, use an appropriate source image from the notes when available or a clean,
answer-neutral Physics diagram workflow. Keep the style classroom-readable and simple.

SOURCE IMAGES
-------------
Reusing a strong source-grounded image from the notes is often better than regenerating it.
Copy it into the section's figures/ folder and reference the local copy.

Do not use a later-section figure if understanding it requires unreleased Physics.
It may only be used early as a generic representation when the question itself requires no
future content.

CURRENT GOLD-STANDARD INTERPRETATION — UNIT 1 LESSONS
================================================================

1. Assessment-plan timing is real. Early sections may not have enough eligible formative
   families; original note/I-can-grounded questions are expected in that case.

2. Practice Set 3 is the Blooket form: 20 questions, all MC, exactly four choices,
   figure-free, and mirrored exactly into CSV.

3. The Blooket deliverable is CSV, not XLSX.

4. Non-MC workspace defaults to ws-80. DOK alone does not justify a larger box.

5. Visuals should be used intentionally in PS1, PS2, and Extra. A section may need only a
   few, but the builder should actively look for opportunities rather than avoiding them.

6. Existing source-grounded note images are valid and often preferable when they directly
   support the question.

7. graph_tool.py should be considered whenever a true quantitative/data graph would add
   representation practice. Do not use it merely to satisfy a graph quota.

8. Physics diagrams and mathematical/data graphs are different visual categories.

9. Four practice forms must feel like parallel practice, not copies.

10. The whole package is designed for clean student use, Notability/print readability,
    and easy conversion of Practice Set 3 into Blooket.
