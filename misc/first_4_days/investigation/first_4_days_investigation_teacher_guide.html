Ball Drop Video Analysis — Teacher Guide

Pairs create the video data source outdoors, then learn Vernier Video Analysis and build a first CER from their own measurements.

OutsidePairs record several ball-drop takes from a designated ground-level recording area.
InsideTeacher models Vernier one move at a time; pairs repeat each move on their best clip.
Student productOne usable video · tracked data · fair interval comparison · one CER

Why this version fits

The investigation now begins with students creating the data source instead of receiving a finished teacher video. That makes the measurement procedure matter: framing, scale visibility, camera stability, tracking consistency, and fair comparisons all affect the evidence they later use. The conceptual scope remains intentionally light. This is a first data-to-CER experience, not a formal free-fall derivation or a precision measurement of g.

Materials

  • Ball that is easy to see against the background.
  • Meter stick or a longer known-length reference that will be clearly visible in the video.
  • Bleacher/location that allows a clear vertical drop while students record from a safe designated area.
  • One recording device per pair.
  • Vernier Video Analysis on student devices.

Before going outside

  • Choose the drop location and a ground-level recording line/zone for students.
  • Teacher or another designated person handles the drop. Students do not climb or reposition around the bleachers unless explicitly directed.
  • Place or hold the known-length reference as close as practical to the ball’s motion plane. A longer reference can be easier to calibrate if the full length remains visible.
  • Ask students to keep the camera side-on to the motion as closely as practical and to avoid panning or zooming during the drop.
  • Plan to make several drops so each pair can capture more than one take.

Run of show

PhaseWhat happensTeacher move / purpose
1. Predict
2–3 min		 Pairs answer what happens to the ball’s speed while it falls. Do not confirm the answer. Establish that a prediction is an idea to test, not evidence.
2. Record outside
10–15 min		 Every pair records several takes of the same drop with the reference length visible. Prioritize safe positioning, a stationary camera, full drop path, and visible scale. Repeat drops so poor clips do not derail the later lesson.
3. Choose clip
2–3 min		 Pairs select the clearest video with the whole reference and useful drop path visible. Ask: “Can you measure from this clip?” rather than “Which clip looks coolest?”
4. Vernier walk-through
8–12 min		 Project one clip. Model import → scale → origin → tracking point → fixed frame step → data display. Students repeat each step. Pause after each major step. This is tool learning, so do not race ahead while groups are still calibrating or tracking.
5. Collect + compare
8–12 min		 Pairs record eight points, calculate distance moved, and choose a fair early/later interval comparison. Press for equal or nearly equal time intervals and actual measured values.
6. CER
10–15 min		 Pairs write claim, evidence, and reasoning, using hints only as needed. Release hints one at a time. Keep the evidence tied to their own video.

Outdoor recording setup

The student diagram intentionally shows only the measurement setup, not the answer. The important recording conditions are:

  • ball path and reference length both visible;
  • reference close to the ball’s motion plane to reduce parallax error;
  • camera held still;
  • camera facing the motion from the side as closely as practical;
  • whole useful drop stays in frame;
  • multiple takes are recorded.

Teacher-controlled hint ladder

Students see only the hint categories. Give the next hint only when the pair needs it.

Hint A — Vernier setup

Say: “Find the known-length object first. Set the scale from that object, then choose an origin. The origin can be anywhere sensible as long as you stay consistent.”

Hint B — Tracking

Say: “Choose one relative point on the ball — usually the center — and click that same point each time. Also make sure you are moving through the video with the same frame step.”

Hint C — Choosing evidence

Say: “Do not compare two intervals unless they lasted about the same amount of time. Find one early interval and one later interval with equal or nearly equal durations, then compare the distance moved.”

Hint D — Reasoning

Say: “Speed compares distance to time. If two intervals lasted the same amount of time, what would a larger distance tell you about the speed during that interval?”

Expected evidence

Strong pattern: For equal or nearly equal time intervals, a later interval normally shows a greater distance moved than an earlier interval. A strong CER cites the pair’s actual measured values and concludes that the ball’s speed increases as it falls.

Strong sample reasoning

If the ball moves farther during the same amount of time, it is moving faster during that interval. Because the later equal-time interval shows a greater distance traveled than the earlier interval, those measurements support the claim that the ball speeds up.

Debrief target

Bring the class back to the three different CER jobs: the claim answers the question, the evidence is measured information that supports the answer, and the reasoning explains why those measurements are relevant. If students naturally use the word acceleration, acknowledge it without turning this lesson into formal acceleration mathematics.

Scope guard: This is a first measured-motion CER and a first use of the video-analysis routine. Do not let software troubleshooting, precision error analysis, calculation of g, or formal constant-acceleration equations take over the lesson.
