Learning Target

I can successfully participate in physics class by following course procedures and using evidence-based reasoning to explain physical phenomena.

I Can Statements
  • I can follow the procedures and routines used in physics class.
  • I can identify the parts of a scientific explanation: Claim, Evidence, and Reasoning (CER).
  • I can make a clear claim that answers a question about a physical phenomenon.
  • I can select and use relevant observations or data as evidence to support my claim.
  • I can explain how my evidence supports my claim using scientific reasoning.

Whiteboard Indy

Course Routines + CER
← Activity Options
Structure

Individual → Independent practice

Setup

Each student gets a whiteboard and one marker.

Directions
  1. Notes are welcome.
  2. Try something before asking for an answer.
  3. Write large and clearly so your work is readable from across the room.
  4. Use your resources: check your notes, then ask a nearby student or the teacher. Do not copy.
  5. Hold up your board when asked and be ready to explain one step.
Goal: Independent attempt + visible thinking
Question sets

Set 1 · Set 2

Looks Like Success
  • Everyone has visible work on a board.
  • Students try before asking for an answer.
  • Mistakes are corrected with an explanation.
Doesn’t Look Like
  • Blank boards while waiting for someone else.
  • Copying a neighbor’s work without discussing it.
  • Tiny work that cannot be checked from a distance.

Whiteboard Partners

Course Routines + CER
← Activity Options
Structure

Partners → Solve, compare, explain

Setup

Partners each need a whiteboard and marker.

Directions
  1. Both partners attempt the problem independently.
  2. Compare answers and work.
  3. If the work differs, explain one step at a time until you find the difference.
  4. Revise your own board when needed.
  5. Be ready for either partner to explain the pair’s reasoning.
Goal: Independent thinking + physics comparison
Question sets

Set 1 · Set 2

Looks Like Success
  • Both partners have their own work.
  • Partners compare reasoning, not just final answers.
  • Either partner can explain the solution.
Doesn’t Look Like
  • One student solves while the other watches.
  • Partners erase differences without discussing them.
  • Only one student can explain what happened.

Rally Coach

Course Routines + CER
← Activity Options
Structure

Partners → Solver + Coach

Setup

Partners share a question set. One student begins as Solver and the other as Coach.

Directions
  1. Solver works the problem and explains each step aloud.
  2. Coach listens, asks questions, and checks the reasoning.
  3. Coach does not take over the problem.
  4. When the problem is complete, switch roles.
  5. Continue alternating roles.
Goal: Explanation + supportive physics coaching
Question sets

Set 1 · Set 2

Looks Like Success
  • The Solver explains instead of working silently.
  • The Coach asks questions rather than giving the next step.
  • Roles switch every problem.
Doesn’t Look Like
  • The Coach grabs the board and solves.
  • The Solver copies steps without understanding them.
  • One person keeps the same role.

Speed Dating Physics

Course Routines + CER
← Activity Options
Structure

Timed partner rounds → Explain, compare, rotate

Setup

Students face a partner with a whiteboard or paper. Teacher controls the rotation.

Directions
  1. Attempt the displayed problem.
  2. Compare work with your partner.
  3. Each person explains one useful step or check.
  4. When signaled, one side rotates to a new partner.
  5. Begin the next problem with the new partner.
Goal: Repeated explanation + meeting classmates
Question sets

Set 1 · Set 2

Looks Like Success
  • Both students attempt each problem.
  • Partners explain rather than simply compare answers.
  • Rotations happen quickly when signaled.
Doesn’t Look Like
  • Students wait for a partner to do the physics.
  • Conversation never reaches the reasoning.
  • Students move before the signal.

Showdown

Course Routines + CER
← Activity Options
Structure

Individual think → Simultaneous reveal → Team discussion

Setup

Groups of 3–4. Each student needs a whiteboard or paper.

Directions
  1. Everyone solves the problem independently and keeps the answer hidden.
  2. On the teacher’s signal, reveal answers at the same time.
  3. If answers differ, compare work and determine why.
  4. Each student corrects their own work.
  5. Prepare one team explanation before the next problem.
Goal: Independent accountability + error analysis
Question sets

Set 1 · Set 2

Looks Like Success
  • Everyone solves before the reveal.
  • Differences lead to discussion of the physics.
  • Students correct their own work.
Doesn’t Look Like
  • Answers are shown before everyone has attempted.
  • The group votes on an answer without checking work.
  • One student fixes everyone else’s paper.

Think, Trade, Agree

Course Routines + CER
← Activity Options
Structure

Think alone → Trade reasoning → Reach agreement

Setup

Partners each need their own work surface.

Directions
  1. Think and solve independently.
  2. Trade explanations with your partner.
  3. Ask at least one clarifying question.
  4. Agree on the physics reasoning, not just the answer.
  5. Revise your own work if your thinking changes.
Goal: Compare reasoning + revise thinking
Question sets

Set 1 · Set 2

Looks Like Success
  • Both students arrive with an independent attempt.
  • Partners ask questions about reasoning.
  • Students revise when another idea is stronger.
Doesn’t Look Like
  • One answer is copied without explanation.
  • Agreement means choosing the louder person’s answer.
  • Students keep an error after the reasoning is resolved.

Round Table

Course Routines + CER
← Activity Options
Structure

Small group → One contribution per turn

Setup

Groups of 3–4. Use one shared board/paper or individual boards as directed.

Directions
  1. First student contributes one step, idea, or check.
  2. Pass to the next student.
  3. Each person must add something useful to the physics thinking.
  4. Ask questions when a step is unclear.
  5. Continue until the problem is solved and checked.
Goal: Shared participation + visible sequence of reasoning
Question sets

Set 1 · Set 2

Looks Like Success
  • Every student contributes.
  • Students connect their step to the previous work.
  • The group checks the completed reasoning.
Doesn’t Look Like
  • One student completes several turns in a row.
  • Students add marks without understanding the prior step.
  • The group stops at an unchecked answer.

Physics Hot Seat

Course Routines + CER
← Activity Options
Structure

One solver → Teammates communicate the physics

Setup

Groups of 3–4. One student is the Hot Seat solver for each round.

Directions
  1. Choose the Hot Seat student.
  2. Teammates describe the problem or needed information using words only when directed.
  3. The Hot Seat student solves from the verbal description.
  4. Compare with the original problem and discuss any mismatch.
  5. Rotate the Hot Seat each round.
Goal: Precise physics language + listening
Question sets

Set 1 · Set 2

Looks Like Success
  • Teammates use clear physics vocabulary.
  • The Hot Seat student explains what they understood.
  • Roles rotate so everyone participates.
Doesn’t Look Like
  • Teammates simply announce the answer.
  • Gestures or pointing replace physics language.
  • The same student remains in the Hot Seat.

Stations

Course Routines + CER
← Activity Options
Structure

Timed station rotations

Setup

Post the station handouts around the room. Students bring their own paper/Notability workspace unless the teacher provides a recording method.

Directions
  1. Go to your assigned starting station.
  2. Work the posted problems and show enough reasoning to check your thinking.
  3. Discuss disagreements before moving on.
  4. Rotate only when the teacher signals.
  5. Continue until the assigned stations are complete.
Goal: Repeated practice + movement + comparison
Question sets

Set 1 Stations · Set 2 Stations

Looks Like Success
  • Students spread out and work at the assigned station.
  • Reasoning is recorded, not just final answers.
  • Groups rotate together when signaled.
Doesn’t Look Like
  • Groups crowd the same station.
  • Students copy answers without doing the work.
  • Students rotate early and interrupt another group.

Find Someone Who

Course Routines + CER
← Activity Options
Structure

Movement + peer interaction

Setup

Each student needs the Find Someone Who handout and something to write with.

Directions
  1. Work alone first and attempt as many problems as you can.
  2. Find a partner and compare completed work.
  3. Work together on one unfinished or disagreed-on problem.
  4. Both students record reasoning they understand.
  5. Find someone new and repeat.
Goal: Meet classmates + compare physics thinking
Handout

Set 1 · Set 2

Looks Like Success
  • Students begin with independent attempts.
  • Partners discuss one problem instead of trading answers.
  • Students work with more than one classmate.
Doesn’t Look Like
  • Walking around before attempting any physics.
  • Collecting answers or names without discussion.
  • One student fills in another student’s sheet.
