Station 1 Answers · Set 2

Problem 1

A group begins a video trial before placing the scale reference in the frame. What should they do?

Answer / target: Stop and follow the setup procedure so later measurements have a valid scale.

Problem 2

A partner wants to overwrite yesterday’s successful data with today’s trial. What routine protects both records?

Answer / target: Use the class naming/version convention and save each trial distinctly.

Problem 3

The group disagrees about who is entering measurements. What routine should be established before continuing?

Answer / target: Agree on the official recorder/shared record and verification process.

Problem 4

A sensor cable is tangled around a stool. What is the correct response before collecting data?

Answer / target: Fix the setup safely according to the class procedure before running the trial.

Station 6 Answers · Set 2

Problem 21

A puck covers equal distances in equal times. Explain why that supports constant speed.

Answer / target: Equal distance per equal time means the distance/time ratio is unchanged.

Problem 22

A ball covers larger distances in equal video intervals. Explain why that supports increasing speed.

Answer / target: Greater distance in the same time means greater speed.

Problem 23

A 9 m hallway takes one model car 3 s and another 6 s. Use $v=d/t$ to explain the speed comparison.

Answer / target: 3 m/s vs 1.5 m/s; first is faster.

Problem 24

The same net force acts on two carts, but one has twice the mass. Use $F=ma$ to predict which accelerates more and why.

Answer / target: The lower-mass cart accelerates more; a=F/m.
