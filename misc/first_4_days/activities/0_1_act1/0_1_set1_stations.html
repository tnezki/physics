Station 1 Answers · Set 1

Problem 1

Your group is ready to track a cart, but nobody has confirmed which shared file is the official trial. What should happen before anyone clicks a point?

Answer / target: Confirm the class file/naming routine and agree on the official trial file so evidence stays attached to the correct record.

Problem 2

A sensor is giving a nonzero reading before the object touches it. What procedure-focused move should the group make before collecting data?

Answer / target: Follow the demonstrated zero/calibration procedure or ask; do not simply subtract a guessed value later.

Problem 3

Two partners record different units for the same measurement. What routine should they use before continuing?

Answer / target: Stop, check the required measurement/unit convention, reconcile the record, then continue consistently.

Problem 4

The bell rings while a cart and sensor are still set up. What should the group do before leaving?

Answer / target: Follow the demonstrated shutdown/cleanup/data-save routine so equipment and evidence are protected.

Station 6 Answers · Set 1

Problem 21

A cart travels farther during each equal time interval. Explain why that supports “the cart sped up.”

Answer / target: Speed is distance per time; greater distance in the same time means greater speed.

Problem 22

A scooter changes from 3 m/s east to 3 m/s west. Explain why velocity changed even though speed did not.

Answer / target: Velocity includes direction.

Problem 23

A model car crosses 8 m in 2 s; another crosses 8 m in 4 s. Use $v=d/t$ to explain which car is faster.

Answer / target: First car: 4 m/s vs 2 m/s; same distance in less time means greater speed.

Problem 24

Two carts feel the same push. The lighter cart accelerates more. Use $F=ma$ qualitatively to explain the pattern.

Answer / target: For the same force, smaller mass gives larger acceleration since a=F/m.
