3. On a train platform, a rider’s speedometer reads 15 m/s at one instant. The rider’s average speed over the entire trip is 11 m/s. Explain what each value describes.

  1. The larger value is average and the smaller value is instantaneous by definition.
  2. 15 m/s is instantaneous speed at that moment; 11 m/s is total distance divided by total trip time.
  3. Both values are instantaneous because both use m/s.
  4. Both values are average because every speed is averaged over time.

4. On a warehouse cart, a rider’s speedometer reads 16 m/s at one instant. The rider’s average speed over the entire trip is 12 m/s. Explain what each value describes.

5. A robot moves at a constant speed of 5 m/s. At first it moves east, then it turns and moves north while keeping the same speed. Compare its speed and velocity before and after the turn.

  1. Both speed and velocity remain constant because the speedometer value is unchanged.
  2. The speed changes but the velocity does not.
  3. Velocity has no direction, so only position changes.
  4. The speed remains 5 m/s, but the velocity changes because its direction changes from east to north.
