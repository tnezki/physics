MARY'S SCIENCE — MSPNG2 STUDENT JOURNAL (HTML EDITION)

START: Open index.html in a browser. Works offline; no server or internet is needed.

HOW THE FORMAT STAYS CONSISTENT
* css/01-tokens.css — one place for font, font sizes, color, spacing, width, and answer-line dimensions.
* css/02-journal.css — shared component rules (headings, questions, model boxes, writing lines, tables, print formatting).
* activities/*.html — content for each lesson. No embedded or inline CSS. Editing content does not change the design rules.
* assets/figures — cropped source photos and diagrams for figures.
* assets/reference-pages — optional scans of original journal pages for comparison; they are collapsed by default.

FIRST-PASS TRANSCRIPTION NOTE
The publisher's master PDF is image-only. Text was recovered by a single OCR pass and organized into editable HTML. Tables and selected illustrations have been recreated or retained as source images. OCR can misread symbols, chemistry subscripts, labels, and dense tables. On original journal page 79, the ammonium chloride questions and aluminum chloride table headers differ in the source; that inconsistency has deliberately been preserved for teacher review. Always compare the HTML against its "Compare with original journal page" reference before distributing a lesson to students. Do not treat the current HTML as a fully proofread publisher-faithful edition.

THIS PACKAGE DOES NOT INCLUDE ACCOMMODATION REWRITES OR THE ANNOTATED TEACHER PAGES.
The original Cereal City Science journal remains the content source. Accommodations can be layered on later using the shared CSS.
