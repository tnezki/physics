Algebra 1 · Unit 0A

Review Practice Problems

0A.1 Rational Number Operations

1. Compute: $-18+7-(-12)+(-5)$. Show enough work to make each sign change clear.

2. Perform the operations and simplify: $\frac{5}{6}-\frac{3}{4}$ and $-\frac{2}{5}\div\frac{6}{7}$.

3. A diver begins at $2.5$ m, descends $6.75$ m, rises $1\frac{1}{2}$ m, then descends $0.8$ m. Write one expression and find the final elevation.

4. Find the distance between $-4.25$ and $3.5$ on a number line using absolute value. Explain why your answer must be nonnegative.

0A.2 Order of Operations and Evaluating Expressions

5. Simplify: $8-3(2^2)+|{-5}|$. Show the order in which you perform the operations.

6. Evaluate $2a^2-3(b-a)$ when $a=-2$ and $b=5$. Show the substituted expression before simplifying.

7. Evaluate $\frac{3x+6}{x-2}$ for $x=5$ and for $x=2$. State what happens for the second input.

8. A student evaluates $-3^2+4$ as $13$ because “negative three squared is nine.” Identify the notation error and find the correct value.

0A.3 Expressions and Properties

9. Use the distributive property to rewrite $-4(2x-5)$.

10. Simplify $7a-2b+3a+9b-4$ by combining like terms.

11. Factor out the greatest common factor from $18x+30$.

12. Two students claim $3(x+4)+2x$ and $5x+12$ are equivalent. Verify or reject the claim using algebraic structure, not just one test value.

0A.4 Solving Equations

13. Solve $5x-7=28$ and check the solution in the original equation.

14. Solve $3(2x-5)+4=25$. Show a balanced pathway and a substitution check.

15. Classify $4(x+3)=4x+12$ as one solution, no solution, or all real numbers. Explain using structure.

16. A club has $14$ points and earns the same number of points in each of $6$ rounds, ending with $50$ points. Write and solve an equation for the points earned per round.

0A.5 Solving and Graphing Inequalities

17. Solve $-4x\gt 20$. Explain why the inequality direction changes.

18. Solve $5-2x\le 17$. State the solution set in inequality form.

19. A storage bin can hold no more than $36$ kg. It already contains $8$ kg, and each identical package has mass $4$ kg. Write and solve an inequality for the possible number of packages.

20. Solve and graph $-5\lt 2x+1\le 9$ on the number line. Label the two boundary values and use the correct open/closed points.
