Predict the Landing Point

Use separate horizontal and vertical relationships to predict where a real horizontal projectile will land.

Learning target: Students will model projectile motion by separating horizontal and vertical components of motion.
Research Question: Can separate horizontal and vertical motion models predict the landing point of a horizontally launched ball?

1. Make a Landing Prediction

A ball will roll horizontally off a table. Before testing, use measurements and the projectile model to predict where its first floor contact should occur.

2. Measure the Horizontal Speed

Equipment: small ball or marble, short ramp/track, table, meter sticks, tape, phone/iPad slow-motion video, Vernier Graphical Analysis video analysis, paper target.
1
Set the ramp so the ball leaves the table horizontally from the same point each trial.
2
Use video analysis or two clearly marked positions near the table edge to estimate the ball's horizontal speed just before launch.
3

3. Calculate the Flight Time

Use the vertical relationship y = 1/2 gt². With y = h, solve for the time to fall. Show your substitution and algebra.

4. Predict the Horizontal Range

Use x = vxt with the same time from the vertical calculation. Mark the predicted landing point on the floor with tape, then place a paper target centered on that mark.

5. Test the Prediction

Release the ball from the same ramp position for three trials. Record the horizontal distance to first floor contact.

6. Defend or Revise the Model

Was the model accurate enough to predict the landing region? Explain how the horizontal and vertical parts of the motion worked together. Identify one realistic source of mismatch without changing the physics model unnecessarily.

7. Critique a Common Error

A student says, "Gravity pulls the ball forward and downward, so the horizontal velocity should get smaller as it falls." Critique the claim for the ideal projectile model.
