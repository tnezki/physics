The Speed Trap

Toy car + four-foot ramp • iPad video timing • 25–30 minutes

Groups3–4 students
Equipment4-ft boards + cars
Output5 average speeds

Purpose

Students compare average speeds over adjacent one-foot segments with the average speed over the full four-foot ramp. They use short-interval averages to estimate speed near a point and explain why velocity changes even when the car's direction stays the same.

Materials / Set Up

  • One toy car and one 4-ft board per group; sturdy books/support; tape for 0, 1, 2, 3, 4 ft marks; soft stop/catch.
  • One iPad per group for side-on video; arrange a stable, stationary camera position that shows every mark.
  • Use a low, stable incline so the car stays on the board and can be filmed clearly. A shallow ramp makes timing easier.
  • Define one consistent crossing point on the car (front bumper) and one fixed release point. Never push the car.
Safety: Secure the ramp and its support. Put a towel or soft barrier after 4 ft so the car cannot roll off a table or into a student. Keep feet and devices out of the path.

How Video Timing Works

  1. Record one continuous 0–4 ft run. The front bumper passes five marks, giving cumulative times t0 through t4.
  2. Set t0 = 0 at the 0-ft crossing (release position). Find each next crossing by pausing/scrubbing the video.
  3. Students calculate interval times by subtraction: 0–1 = t1 − t0; 1–2 = t2 − t1; 2–3 = t3 − t2; 3–4 = t4 − t3; 0–4 = t4 − t0.
  4. The same complete run is used for all five intervals. Do not release the car at 1, 2, or 3 ft: restarting would change the motion being compared.
Check the iPad first: Slow-motion recording makes the crossing easier to see, but the built-in Photos player may not show precise fractional-second timestamps or advance one frame at a time. If needed, use an available video-analysis/frame-step app that reports the recording's real time, or use a suitably visible external timer in the shot. For frame counts, real time = number of recorded frames ÷ the camera's recorded frames per second (for example 120 frames ÷ 120 fps = 1.00 s). Do not use the slowed playback duration as elapsed time. If precise timing is unavailable, use a shallower ramp and timed segments; acknowledge uncertainty.

Suggested Flow

TimeAction
0–5 minSecure ramp, mark feet, predict whether speeds will match.
5–12 minFilm one clean run. Repeat only if necessary for a usable video.
12–22 minRead crossing times, subtract to find five intervals, calculate five average speeds.
22–30 minCompare values and write short evidence-based conclusion.

Teacher Check: Example Arithmetic

Illustrative values, not prescribed results: t0 = 0.00 s, t1 = 0.65 s, t2 = 1.03 s, t3 = 1.33 s, t4 = 1.59 s.

Expected Answers / Discussion

  • A: For a car speeding up down the ramp, the average speed is typically smallest from 0–1 ft and greatest from 3–4 ft. Results may be noisy with imprecise timestamps.
  • B: No. The full 0–4 ft speed includes the slower beginning; students cite both measured speeds.
  • C: 3–4 ft better estimates speed near the bottom than 0–4 ft because it spans a shorter, more local part of the motion. It is still an interval average, not a true instantaneous measurement.
  • D: The car rolls downhill in one direction, but its speed increases; velocity changes because velocity contains both magnitude and direction.
  • Conclusion: One full-trip average hides the differences along the ramp. Student conclusions should include at least two numbers from their own table.
Scope: Students calculate average speed = distance/time. They discuss instantaneous speed only as a local estimate from a short interval. Do not require acceleration calculations (Section 2.3). All units are feet and seconds, so answers are in ft/s; converting to metric is optional.

Common Issues

  • Subtracting the wrong times: 1–2 ft is t2 − t1, not the cumulative t2.
  • Misreading slow-motion: Use recorded real time or frame count ÷ actual recording fps, not slowed playback time.
  • Inconsistent release: Change neither the incline nor the release point. Start a new full run if the car is pushed or the camera moves.
  • Almost identical or inconsistent speeds: Check crossings at the same point of the car, improve video timing, and repeat the complete run if needed.

Connection Forward
