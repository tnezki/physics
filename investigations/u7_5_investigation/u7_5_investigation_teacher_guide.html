Why This Investigation Fits Section 7.5

The investigation integrates every Section 7.5 target: path tracing, series/parallel behavior, voltage/current evidence, equivalent resistance, and overload protection. It uses bulbs for visible path evidence and labeled resistors for cleaner equivalent-resistance mathematics.

Materials

  • Low-voltage battery pack
  • Two identical miniature bulbs and holders
  • Switch and wires
  • Digital multimeter
  • 100-ohm and 220-ohm resistors with adequate power ratings

Before Class

  1. Prepare a reference series and parallel diagram for teacher troubleshooting only.
  2. Verify resistor labels and meter fuses.
  3. Use current-limited/low-voltage sources.

Expected Observations / Evidence

Series and parallel circuits produce clearly different failure behavior. Meter evidence should support same current in a series path and shared voltage across parallel branches, within experimental limitations. Equivalent-resistance calculations should pass the greater-than/less-than reasonableness checks.

Watch for: Keep household safety conceptual and low-voltage. Never model a short circuit by directly shorting a classroom battery. Do not use miniature-bulb cold resistance as the clean resistor value for the equivalent-resistance calculation.

Sample Equivalent-Resistance Work

For 100 Ω and 220 Ω in series: Req = 100 + 220 = 320 Ω.

In parallel: 1/Req = 1/100 + 1/220 = 0.01455 Ω-1, so Req ≈ 68.8 Ω. The result is correctly smaller than either branch resistance.

Expected Evidence

  • Series: same current through the single path; source voltage is shared among devices; removing one bulb opens the entire path.
  • Parallel: branch voltages are approximately the source voltage; current divides among branches; another branch can remain complete if one is opened.
  • Adding parallel branches lowers equivalent resistance and can increase total source current.

Safety / Common Problems

  • Accidental short circuit: Open the switch immediately and check branch wiring before reconnecting.
  • Bulb measurements vary: Treat brightness and bulb resistance qualitatively; use the labeled resistors for equivalent-resistance calculations.
