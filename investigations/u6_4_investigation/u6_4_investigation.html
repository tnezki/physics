Physics - Unit 6 - Section 6.4 - Investigation

Measure a Lens: Focal Length and Magnification

Use repeated object-screen measurements to test the thin-lens model and compare predicted magnification with the observed image.

Learning target: Use ray and thin-lens models to connect focal length, object distance, image distance, real images, and magnification.
Research Question: Does one focal length consistently describe the same converging lens when object and image distances change?

1. Predict What Stays the Same

The same lens will be used for three different object positions. Predict which quantities will change and which lens property should stay constant.

2. Set Up the Optical Bench

Equipment: converging lens + holder, illuminated arrow/object, white screen, meter stick or optical bench, ruler.
1
Align object, lens center, and screen at the same height. Measure all distances from the center of the lens.
2
Choose an object distance that produces a clear projected image. Move the screen until the image is sharp, then measure do, di, object height ho, and image height hi.
