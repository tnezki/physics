Practice Set 3 — Section 2.1: Motion and Reference Frames

1. Which term names the object, surface, or viewpoint used as the comparison for motion?

  1. reference frame
  2. acceleration
  3. speed
  4. distance

2. A phone stays on a bus seat. Relative to the seat, the phone is

  1. moving forward
  2. at rest
  3. moving backward
  4. changing direction

3. The same phone is moving relative to

  1. the seat
  2. the bus floor
  3. a roadside sign
  4. a passenger beside it

4. Which everyday frame is usually implied when a runner’s speed is reported?

  1. the runner’s shoe
  2. the runner’s shirt
  3. the Sun
  4. the ground

5. Which statement explicitly includes a reference frame?

  1. The cart is at rest relative to the platform.
  2. The cart moves fast.
  3. The cart travels far.
  4. The cart moves for 5 s.

6. A drone stays over one point on a moving boat. Which pair of descriptions can both be correct?

  1. moving relative to boat and at rest relative to shore
  2. at rest relative to boat and moving relative to shore
  3. at rest in every frame
  4. moving at the same speed in every frame

7. Why can two observers disagree about whether a suitcase is moving without either being wrong?

  1. Motion has no physical meaning.
  2. One observer measures time differently because of mass.
  3. They may use different reference frames.
  4. Every object has two positions at once.

8. Which revision best fixes “The passenger is not moving”?

  1. The passenger is not really moving.
  2. The passenger is not moving anywhere.
  3. The passenger is at rest relative to all objects.
  4. The passenger is at rest relative to the bus seat.

9. A classroom desk is at rest relative to the floor but moves with Earth around the Sun. What idea does this illustrate?

  1. motion is relative
  2. speed is always constant
  3. Earth is stationary
  4. all frames are identical

10. For describing a person walking inside a train, which frame would best show the person’s motion through the aisle?

  1. a distant star
  2. the train floor
  3. the station clock
  4. the Sun

11. Observer A rides on a cart and says a box is at rest. Observer B stands beside the track and says it is moving. Which evaluation is best?

  1. Observer A must be wrong because the cart moves.
  2. Observer B must be wrong because the box does not slide.
  3. Both can be correct because each compares the box with a different frame.
  4. The box must switch between rest and motion.

12. A student says there is one “true” answer to whether an object moves. Which response is strongest?

  1. The answer is always based on Earth.
  2. The answer is always based on the moving object.
  3. Motion cannot be measured.
  4. The answer depends on the stated reference frame, so the claim is incomplete.

13. A rider sits on a subway. Which statement can be true?

  1. at rest relative to seat and moving relative to station
  2. moving relative to seat and at rest relative to station
  3. at rest relative to every frame
  4. moving relative to every frame at the same speed

14. Which example best shows one object using two reference frames?

  1. a timer read twice
  2. a backpack compared with a train seat and a platform
  3. a ruler used twice
  4. a car with two passengers

15. Which phrase identifies the frame in “The cyclist is moving relative to the road”?

  1. cyclist
  2. moving
  3. relative to the road
  4. the

16. A moving walkway carries a standing traveler. Relative to the walkway the traveler is at rest; relative to the floor the traveler is moving. This means

  1. the traveler has no real motion
  2. the floor is not a valid frame
  3. the walkway must be accelerating
  4. rest is relative to the chosen frame

17. Which observer most naturally uses the ground as a reference frame?

  1. a spectator beside a race track
  2. a passenger seated on a train
  3. a person standing on a moving walkway
  4. an astronaut inside a spacecraft

18. What should be added first to the statement “The book moved 2 m” to make it a clearer motion description?

  1. the book’s color
  2. the reference frame
  3. the book’s mass
  4. the room temperature

19. Two videos show different motion for the same passenger, one from inside a bus and one from a building. Which explanation fits?

  1. One camera must be broken.
  2. The passenger changes mass between videos.
  3. The cameras are fixed to different reference frames.
  4. Motion is independent of viewpoint.

20. Which statement about Earth’s surface is correct?

  1. It is the only frame allowed in physics.
  2. It is at rest relative to every object.
  3. It makes all moving objects have the same speed.
  4. It is a convenient common frame for everyday nearby motion, not the only valid frame.
