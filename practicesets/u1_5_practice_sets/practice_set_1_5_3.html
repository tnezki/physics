Practice Set 3 — Section 1.5: Modeling Forces in the Real World

1. The first step in a force model is to

  1. choose the object being modeled
  2. draw velocity
  3. add inertia
  4. calculate mass

2. Each force arrow should represent

  1. motion direction
  2. a real interaction acting on the chosen object
  3. inertia
  4. the object’s path

3. Balanced forces mean

  1. no forces act
  2. all arrows point right
  3. net force is zero
  4. the object must be at rest

4. A nonzero net force means

  1. motion is constant
  2. no forces act
  3. mass is zero
  4. motion is changing

5. Which is a modeling error?

  1. drawing an inertia force arrow
  2. drawing weight from Earth
  3. drawing support from a floor
  4. drawing tension from a rope

6. A cart has 45 N right and 45 N left. Which motion could fit?

  1. speeding up right
  2. constant straight-line motion
  3. slowing while moving right only
  4. turning because of horizontal imbalance

7. A box has 70 N right and 30 N left. Net force?

  1. 100 N right
  2. 40 N left
  3. 40 N right
  4. 0 N

8. A person stands still on a scale. Which force pair belongs on the person?

  1. support down and weight up
  2. inertia down and motion up
  3. net force up only
  4. weight down and support up

9. A crate moves right while net force points left. Which can be true?

  1. It is slowing while still moving right.
  2. It must speed up right.
  3. It must have constant velocity.
  4. It must be at rest.

10. A hanging object supported by two angled ropes is at rest. What must the vector sum of both tensions and weight equal?

  1. the weight only
  2. zero
  3. the larger tension
  4. the speed

11. Text says constant speed right; diagram shows 80 N right and 40 N left. Best critique?

  1. They agree because motion is right.
  2. The diagram needs an inertia arrow.
  3. The unequal forces give nonzero net force, so the diagram and motion description conflict.
  4. The left force should be removed automatically.

12. A standing person’s diagram shows only weight down. Best revision?

  1. Remove weight.
  2. Add an inertia force up.
  3. Add a forward motion force.
  4. Add the upward support force from the scale/floor so the forces can balance.

13. Which model-building choice is correct?

  1. Choose one object and draw only forces acting on it.
  2. Draw every force in the entire scene on one diagram.
  3. Use motion arrows as force arrows.
  4. Add inertia as a force.

14. A force arrow’s source should be

  1. the object’s speed
  2. an interacting object such as Earth, a surface, rope, or hand
  3. the final net force only
  4. the diagram scale

15. Which force set is balanced?

  1. 30 N right and 10 N left
  2. 15 N up and 5 N down
  3. 20 N left and 20 N right
  4. 12 N right only

16. Which force set is unbalanced?

  1. 25 N up and 25 N down
  2. 18 N left and 18 N right
  3. 10 N up + 10 N down
  4. 40 N right and 15 N left

17. Zero net force on a moving object means it can

  1. continue with constant velocity
  2. must stop
  3. must speed up
  4. must turn

18. A rightward net force on a cart moving right is consistent with

  1. constant speed only
  2. speeding up to the right
  3. slowing to the right
  4. zero motion change

19. Which critique is physically valid?

  1. Every moving object needs a forward force.
  2. Inertia is the main forward force.
  3. A forward force arrow cannot be justified only by forward motion; name a real interaction.
  4. Net force always points with velocity.

20. How should a mismatched model be revised?

  1. Keep all arrows and change nothing.
  2. Add more decorative arrows.
  3. Remove labels only.
  4. Make the interactions/vector sum and motion description mutually consistent.
