Practice Set 1 — Section 6.4: Lenses and Optical Systems

1. How does a converging lens differ in shape and ray effect from a diverging lens?

2. Name two standard rays commonly used to construct a simple converging-lens ray diagram.

3. Define focal point and focal length.

4. What observation distinguishes a real image from a virtual image?

5. Name one optical device that uses a converging lens to form a real image.

6. Use the labeled converging-lens figure as a reference. Predict how the focal-point positions would change for a stronger converging lens with a shorter focal length, and explain how that would alter the path of initially parallel rays.

7. A converging lens has $f=12$ cm and an object is at $d_o=36$ cm. Use the thin-lens equation to find $d_i$.

8. An object 4 cm tall forms an image 10 cm tall. Calculate the magnification magnitude.

9. A projected image appears sharply on a wall. Classify the image as real or virtual and explain what the ray model must show.

10. An object is moved closer to a converging lens while remaining outside the focal point. Explain qualitatively why refocusing changes the image distance.

11. A student says, “A lens creates new light to build the image.” Critique the claim using rays already coming from the object.

12. A ray diagram sends a ray parallel to the principal axis through a converging lens but bends it away from the far focal point. Diagnose and repair the model.

15. Focal length is measured between

16. Which observation demonstrates a real image?

  2. The image is upright.
  3. The image is enlarged.

  1. 15 cm
  2. 20 cm

  4. 40 cm
  5. 10 cm

  1. 3
  2. 4

  4. 8

19. A simple magnifier produces its familiar enlarged upright view when the object is

  1. inside the focal length of a converging lens
  2. beyond the focal point of a diverging lens only

  4. behind the eye
  5. inside an opaque filter

20. What is wrong with saying a lens “creates the image light”?

  1. The lens redirects light already coming from the scene; it does not generate the scene rays.
  2. Only diverging lenses create light.
  3. The statement is correct for cameras.
  4. Real images require new light.
  5. Virtual images contain no rays reaching the eye.
