Practice Set 1 — Section 7.5: Complex Electric Circuits

1. State the defining path difference between a series circuit and a parallel circuit.

2. Why does an open gap in the only path stop steady current?

3. In a parallel network, what happens to current at a junction?

4. Which quantity is the same through each element in an ideal series path: current or voltage drop?

8. Two identical 10 Ω resistors are connected in parallel. Calculate the equivalent resistance.

9. A 12 V source is connected across two ideal parallel branches. Explain the voltage across each branch and how total source current relates to branch currents.

12. Two identical bulbs are compared: one pair in series and one pair in parallel on the same ideal source. Explain why the brightness behavior differs using equivalent resistance, branch voltage, and energy-transfer rate rather than memorized labels.
