1. A backpack stays beside a traveler inside a airport moving walkway that is moving relative to the terminal floor. Which statement correctly explains the backpack’s motion?

A. It can be at rest relative to the airport moving walkway while moving relative to the terminal floor; motion depends on the chosen reference frame.
B. It is at rest in every reference frame because it does not slide.
C. Changing the reference frame changes the object’s mass, so its motion changes.
D. It must have exactly the same motion in every reference frame.

2. A description says, “The backpack remains beside the traveler while the terminal floor appears to move past.” Which reference frame is used when the backpack is described as remaining beside the traveler?

A. no reference frame is needed
B. the terminal floor frame
C. the airport moving walkway / traveler frame
D. the object itself as the only possible frame

3. A traveler says the backpack is at rest in the airport moving walkway, while an observer at the terminal floor says it is moving. Which explanation is best?

A. Only the Earth observer can be correct because Earth is the unique true frame.
B. Both descriptions can be correct because they use different reference frames; the terminal floor is a convenient shared Earth-based frame for everyday motion.
C. Both observers must report zero velocity if the object is not sliding.
D. Only the moving observer can be correct because objects carried by vehicles are always at rest.

4. A cart travels a total distance of 96 m in 12 s. What is its average speed?

A. 0.125 m/s
B. 54 m/s
C. 1152 m/s
D. 8 m/s

5. During a trip, a speedometer reads 14 m/s at one instant. The trip’s average speed is 8 m/s. Which interpretation is correct?

A. 14 m/s is instantaneous speed at that moment; 8 m/s represents total distance divided by total trip time.
B. Both values are averages because all speeds depend on time.
C. The larger value must always be the average speed.
D. Both values are instantaneous because both use m/s.

6. A robot moves at a constant speed of 4 m/s. It first moves east, then turns and moves north at the same speed. What changes?

A. Neither speed nor velocity can change when the magnitude stays the same.
B. Its velocity remains constant because its speed is constant.
C. Its speed remains 4 m/s, but its velocity changes because the direction changes from east to north.
D. Its speed changes but its velocity does not.

7. A cart’s velocity changes from 2 m/s to 14 m/s in 4 s. What is its average acceleration?

A. 3 m/s²
B. 48 m/s²
C. 3.5 m/s²
D. 4 m/s²

8. An object is moving east and is slowing. Which statement best describes why it is accelerating?

A. Acceleration occurs only when an object is moving faster than 10 m/s.
B. Its velocity is changing; while it slows, acceleration has a component opposite the east velocity.
C. Acceleration must be zero whenever speed is constant.
D. Acceleration and velocity must always point in the same direction.

9. Use the velocity–time graph. What is the sign of the acceleration, and what graph feature supports the answer?

A. acceleration cannot be determined from a velocity–time graph
B. positive acceleration because the slope of the velocity–time graph is positive.
C. zero acceleration because velocity is on the vertical axis
D. negative acceleration because the line is not horizontal

10. A steel ball and a wooden ball are released together from the same height in a vacuum chamber near Earth. What should happen?

A. The heavier object must arrive first because gravity gives it greater acceleration.
B. The lighter object must arrive first because it has less inertia.
C. Neither object accelerates because a vacuum removes gravity.
D. They should fall with the same acceleration and arrive together if released with the same initial velocity, because ideal free-fall acceleration does not depend on mass.

11. An object is dropped from rest with negligible air resistance. Using $g \approx 10\text{ m/s}^2$, how much speed does it gain after 2 s?

A. 12 m/s downward
B. 20 m/s upward
C. 20 m/s downward
D. 10 m/s downward

12. For ideal free fall from rest, use $d=\frac12gt^2$ with $g \approx 10\text{ m/s}^2$. Compare total distance after 1 s and 2 s, then choose the statement that also correctly addresses strong air resistance.

A. Distance is inversely proportional to $t^2$.
B. 5 m after 1 s and 20 m after 2 s; the ideal $t^2$ pattern does not apply once significant air resistance changes the acceleration.
C. All falling objects always follow the same $t^2$ pattern even at terminal speed.
D. The distance increases by the same amount every second because acceleration is constant.

13. Which description correctly represents a velocity vector for motion left at 5 m/s?

A. an arrow pointing opposite left with the same scaled length
B. an arrow pointing left with zero length
C. a dot with no direction information
D. an arrow pointing left with a length scaled to represent 5 m/s

14. Vector A is 4 cm long and points east. Vector B is 4 cm long and points north. Did the velocity change?

A. No; direction is not part of velocity.
B. Yes only when the object comes to a complete stop.
C. No; equal arrow lengths always guarantee equal velocity.
D. Yes. Velocity changes because direction changes.

15. Use the position–time graph. Which motion description and model critique are both consistent with the graph?

A. The object is moving up or down a physical hill shaped like the line.
B. The object is at rest because the graph is a straight line.
C. The object moves in the positive direction at constant velocity 2 m/s; the graph’s vertical position is a coordinate, not a picture of physical height.
D. The object is accelerating because position changes.

16. A cart travels 60 m in 8 s, then 40 m in 4 s. What is its average speed for the entire trip?

A. 8.33333 m/s
B. 12 m/s
C. 8.75 m/s
D. 100 m/s
